# 2020년 전체 데이터 갱신

사용자 승인 범위: 신고가·거래대금 6개 시장, 종목 차트·확정 실적, 국내 섹터·투자자 수급·동일 날짜 지수·신용잔고 전체.

수집·검증 작업 폴더: `data/tmp_2020/worktree`. 최신 2021년 배포본 `6aef02735`에서 분리했다. 기존 원본·미커밋 파일은 별도로 보존하고, 검증한 결과를 원래 작업 폴더에 반영했다. 기존 현재 시세·피어 비교 생성 파일은 유지하며, 캘린더 색인에는 새 연도를 추가했다. 직전 요청의 화면 순서·상장명·신한지주 직원 수 수정도 유지한다.

## 보존 및 자료 기준

- 기존 일별 원본 SHA256과 실적·일봉·반도체·신용·수급 원본을 작업 폴더의 `data/tmp_2020/baseline`에 보관했다. 원본은 실제 관측만 추가하고 기존 기간은 보존한다.
- KRX 금액은 FinanceData/marcap 고정 revision `eeed0817d1478597b738a3a6149c170ec7e3f4cb`의 2020년 Parquet. SHA256은 공유 캐시 `data/tmp_korea_recalculation/source/marcap-2020.source.json`에 있다.
- 공식 휴장 일정은 `data/market-closures/2020.json` 및 유럽 거래소별 파일. 한국 8/17 임시휴장, 중국 1/31 코로나19 연장휴장, 일본 올림픽 관련 휴일 이동, 영국 5/8 변경을 반영한다. 반일장은 거래일이다.
- 예상 거래일: 한국 248, 미국 253, 일본 242, 중국 243, 대만 245, 유럽 258. 일본 10/1은 JPX 공식 발표에 따른 시스템 장애 전면 거래중단으로 제외한다. 그 밖의 누락은 휴장으로 바꾸지 않고 원본으로 대조한다.
- 해외 거래대금은 종가×거래량 추정치다. 유럽 부분 복원·현행 상장 명단으로 인한 상장폐지 누락 한계를 유지한다.
- Yahoo 과거 실적 미제공을 SEC XBRL Frames API로 보완한다. 종목·거래소·회사·CIK·통화·실제 회계기간을 검증하고 하나의 공시 안에서 값을 구성한다. 분기는 실제 61~121일 기간만 허용하며 연간을 나누거나 누적 실적에서 추정하지 않는다.

## 진행 및 재개

원본 수집 프로세스별 명령·PID·로그는 작업 폴더의 `data/tmp_2020/*.process.json`, `*.log`에 있다. 초기 실행 도구는 원래 작업 폴더의 `data/tmp_2020/launch.py`. SEC는 별도 `sec.log`, `sec-error.log`를 확인한다. 캐시는 기존과 공유하지만 요청 범위별 키로 원본을 구분한다.

```powershell
python scripts/backfill_stock_information_2020.py collect --workers 12
python scripts/backfill_sec_financials_2020.py collect
python scripts/backfill_sec_financials_2020.py apply
python scripts/backfill_stock_information_2020.py export
python scripts/extend_stock_history_2020.py
python scripts/refresh_stock_information_history.py --state-dir data/tmp_2020_history
python scripts/backfill_sector_history_2020.py
python scripts/recalculate_korea_history.py --start 2020-01-01 --end 2020-12-31 --audit-tag 2026-10-30-2020 --apply
python scripts/audit_calendar_2020.py
python scripts/audit_stock_information_2020.py
python scripts/audit_preservation_2020.py
```

수집은 완료됐다. 위 명령은 원본 캐시와 상태 DB를 이용한 재개·재검증용이다.

## 최종 수집·전수 검증

- 신고가·거래대금 각각 **1,489일**: 한국 248, 미국 253, 일본 242, 중국 243, 대만 245, 유럽 258. 국내 섹터·수급·동일 날짜 지수 248일, 신용잔고 249개 보고일이다. 두 캘린더의 전체 거래일과 유럽 개별 거래소 휴장을 대조했다.
- 전체 **24,694종목**의 현재 정보·2020년 실적·일봉 조회를 마쳤다. 세 단계 모두 미처리 항목이 없다.
- 2020년 종료 확정 실적 **3,487종목**, 매출 2,787종목, 영업이익 2,751종목이다. 확인된 분기는 **10,988건**이다. SEC 원본은 3,485종목·14,405행을 보완했다. 제공처에서 미제공인 **21,207종목**은 예외 목록에 남겼으며 연간이나 누적 실적에서 분기를 추정하지 않았다. 한국·대만 등에서 이전 연도 실적이 제공되지 않는 한계를 명시한다.
- 차트: 2020년 초 포함 17,861종목, 이후 상장 6,073종목, 원본 범위 제한 742종목, 기존 미제공 18종목이다. `data/information-audit/2020/coverage-exceptions.json`에서 종목별 이유를 확인한다.
- 원본이 짧아졌거나 조정 방식이 달라지면 기존 가격을 별도 원본 스냅샷으로 유지한다. 과거 구간을 채우는 명시적 실행에서는 최근 7일 이내의 온전한 원본 곡선을 사용할 수 있게 했으며 실제 제공 종료일을 그대로 표시한다. 차트 새로고침도 일치하는 가격만 연결하고 조정 기준이 다르면 저장된 곡선을 유지한다.
- 2021년 기준본의 기존 일별 원본 **15,266개 SHA256 동일**, 확정 실적 **227,038건**, 가격 관측 **29,375,319개**, 반도체 102종목, 수급 1,426일·신용 1,430개 보고일을 보존했다.
- 원래 작업 폴더도 별도로 전수 대조했다. 기존 일별 원본 **12,016개 SHA256 동일**, 확정 실적 **201,364건**, 가격 관측 **23,979,876개**, 반도체 102종목, 수급 1,176일·신용 1,179개 보고일이 모두 남아 있다. 새 기준본과 달랐던 기존 실적 565개 기간은 원래 보고 행 전체를 유지했다. 수급의 기존 수집 시각도 유지하고, 다른 반도체 원본 곡선은 별도 스냅샷으로 보존했다. 결과는 `original-workspace-preservation.json`에 있다.
- 새 일봉의 마지막 날짜가 섹터 기준일보다 짧을 때는 같은 종목·통화의 검증된 기존 전체 곡선을 선택한다. 기준본과 동일한 스냅샷 821개에 완전성을 표시하고, 현재 섹터에 필요한 원본 1년 구간 1,920개를 추가 보존했다. 서로 다른 조정 가격을 섞지 않는다. 은행 섹터 추이·1년 선택·새로고침 회귀 검증을 통과했다.
- 공개 압축 보고서 **14,848개**를 생성 JSON과 전체 대조해 숫자·정밀도가 동일함을 확인했다. 원래 작업 폴더의 최종 운영 경로 빌드는 **996.01 MiB**, 96,078파일로 1 GiB 이하이다. 운영 API 주소·배포 기본 경로·404 대체 파일을 확인했다.
- Python **227개**, 프런트엔드/API 단위 테스트 **63개**를 통과했다. 로컬 API에서 AAPL의 2019-12-20 이후 일봉, 2020년 조회 범위, 2020-01-02 코스피·코스닥 수급과 동일 날짜 지수를 확인했다. Worker 배포 묶음 생성도 통과했으며 운영 API에는 아직 배포하지 않았다.
- 실제 브라우저에서 두 캘린더 × 6개 시장의 연간·월별 조회, 상세 화면 8개, `2020년~` 가격 구간, 원본과 일치하는 확정 실적 또는 0건 미제공 표시, 신용잔고, 원본 재조회와 1440/320px를 검증했다. 투자자 수급은 매수·매도·순매수·지수의 값, 날짜·휴장일·URL·시장 합계·재조회 실패 시 보존 및 1440/390/320px를 통과했다.
- 원래 작업 폴더의 `/find_peer_stock/` 빌드에서도 2020년 브라우저 검증과 은행 섹터 회귀 검증을 다시 통과했다. 섹터 화면 순서·정식 종목명·신한지주 직원 수·26개 정렬 동작·원본 새로고침·모바일 표시를 확인했다.

원래 작업 폴더 반영 전 백업은 `data/tmp_2020/original-workspace`, 공개 파일 이전 사본은 `data/tmp_2020/original-publication`에 보관한다. `integration.json`, `publication-preservation.json`과 최종 원본 보존 검사에 파일별 근거를 남긴다. 운영 사이트와 API 배포는 이번 로컬 갱신에 포함하지 않았다.

## 운영 배포 진행

사용자가 2020년 운영 사이트와 API 배포를 명시적으로 요청했다. 기존 작업 폴더를 보존하고 `data/tmp_2020/deploy-worktree`에서 최신 운영 커밋 `90a26040a`와 병합했다.

- 운영 API 버전 `1e7bd3c4-ec8c-4269-b5fa-876fbd1682d2` 배포 완료. 운영 주소에서 AAPL 일봉 시작 `2019-12-20`, 2020년 실적 조회 범위, `2020-01-02` 코스피·코스닥 수급과 동일 날짜 지수(2,175.17 / 674.02)를 확인했다(`api-production.json`). 원본 실적 미제공 응답은 저장된 SEC 실적을 대체하지 않는다.
- 최신 운영 실적 229,242행과 가격 29,586,926개를 병합·보존했다. 현재 운영의 수정 실적을 표시하고 이전 원본 2,395행은 `prior_financial_snapshots`로 유지했다. 서로 다른 조정 가격은 연결하지 않고 원본 보존본에 남겼다(`deployment-integration.json`).
- 화면에서 사용하지 않는 불연속 가격 보존본은 배포에서 제외하되 저장소의 압축 원본에는 그대로 둔다. 2020년 주 가격 이력과 섹터에서 사용하는 완전한 이전 곡선은 계속 배포한다. 원본 불변·완전 곡선 보존 테스트 10개 통과.
- API 26개, 프런트엔드 37개 및 타입 검사 통과. 로컬 운영 경로에서 2020년 캘린더·상세 8개·실적·원본 재조회·신용잔고, 수급·지수·실패 시 보존·모바일과 은행 섹터·정식 이름·26개 정렬 동작 검증을 통과했다.
