# 날짜별 투자자 수급 · 지수 캘린더

`/investor-flows`, 주 메뉴 ‘투자자 수급’을 추가했다. 개인·외국인·기관의 매수/매도 총액과 순매수를 날짜별로 보고 같은 거래일의 코스피·코스닥 지수를 확인한다.

- 공개 Npay 증권 KRX 일별 원자료를 수집했다. 최초 자료는 2024-01-02~2026-10-26의 684개 거래일(2024년 244일, 2025년 242일, 2026년 198일)이며 두 시장의 투자자 금액과 지수가 모두 있는 날짜만 저장했다.
- 원본: `https://stock.naver.com/api/domestic/market/trend/daily?tradeType=KRX&marketType=KOSPI&startIdx=0&pageSize=200` 및 KOSDAQ. `startIdx`는 행 오프셋이 아닌 페이지 번호다. `bizdate`가 무시되는 것을 확인해 반환된 실제 날짜를 검증하며, 해당 날짜가 없으면 최신 자료로 대체하지 않는다.
- 지수 원본: `https://m.stock.naver.com/api/index/KOSPI/price?pageSize=60&page=1` 및 KOSDAQ. 조회 날짜와 지수 날짜가 다르면 수집/표시를 거절한다. 각 지수의 변화폭·등락률은 전 거래일 대비 원본 값이다.
- 금액은 원본 KRW를 보존하고 화면에서 억원으로 표시한다. `buyPrice`, `sellPrice`, `diffValue`를 매수·매도·순매수에 각각 사용한다. 백만원 단위 반올림 차이만 허용하고 음수 매수/매도·중복 투자자·미제공 필드·합계 불일치를 거절한다.
- 외국인은 9000+9001(기타외국인), 기관은 금융투자·보험·투신·사모·은행·기타금융·연기금·국가/지자체 분류 합계다. 기타법인 등은 별도이며 개별 원본 분류도 펼쳐 볼 수 있다. 기관/전체 합계 행 7050/9999는 중복 집계하지 않는다.
- 전체/코스피/코스닥 전환, 지수 카드, 투자자 요약, 시장별 매매 표, 세부 분류, 월별 일별 기록을 제공한다. 캘린더는 실제 자료가 있는 날짜만 활성화한다. 날짜·시장은 URL로 유지한다. 장중 자료는 잠정으로 표시한다.
- 새로고침은 선택 날짜를 운영 API로 다시 요청한다. 원본 조회가 실패하면 이전 기록을 유지하며 오류를 표시한다. 과거 날짜를 새로고침해도 최신 날짜로 이동하지 않는다.
- 매일 자동 수집을 기존 빌드에 연결했다. `node scripts/refresh_investors.mjs`는 최근 14일을 갱신하고 기존 과거 기록을 보존한다. 오전 9시 전과 당일 마감 확정 자료 보유 시에는 기존 자료를 유지한다. 전체 재수집은 `--full`, 정적 발행은 `publish`다. `data/investors/index.json`이 원본 저장소이며 프런트엔드 복사본은 재생성한다.

검증: API 24개, 프런트엔드 투자자 테스트 3개, Python 208개, 타입 검사와 배포 빌드 통과. 브라우저에서 실제 원본 금액/단위·순매수 합계·두 지수의 날짜/값·시장 전환·2024년 캘린더·휴장 비활성·URL 복원·과거 원본 재조회·실패 시 보존·1440/390/320px 표시를 확인했다. 기존 섹터 캘린더 검사도 통과했다. 배포 파일 970.98 MiB로 기존 모든 기록과 함께 Pages 제한 이내다.

운영 API 버전: `7d8ee465-fb1d-430d-ba52-af9cde5f62f2`. 실제 API에서 2024-01-02의 두 시장 금액과 같은 날짜 지수 응답을 확인했다. 화면 캡처는 `data/tmp_investor/ui/`에 저장했다. 사이트 push/배포 및 운영 검증 결과는 완료 후 추가한다.
