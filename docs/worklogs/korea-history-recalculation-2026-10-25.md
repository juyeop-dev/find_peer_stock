# 2026-10-25 국내 과거 기록 재계산

새 분류·시가총액 가중 기준을 과거 전체에 적용했다. 사용자는 15:30 원본이 없는 과거 거래대금에 대해 **KRX 일별 확정 자료로 교체**하는 방식을 선택했다. 일별 합계는 시간외가 포함될 수 있으므로 정규장 15:30 시점 값이라고 표시하지 않는다.

- 섹터 128거래일 × 오늘/1주/1개월/3개월/1년을 재계산했다. 127개 저장 아카이브에서 날짜가 일치하는 291,831개 종목·일의 시총·거래대금을 보완했다. 이 중 2024년 123거래일은 이전에 시총이 없어 가중 수익률을 표시하지 못하던 기록이다.
- 원본 매칭이 되지 않은 601개 종목·일에는 현재 시총을 넣지 않았다. 날짜별 매칭률은 모두 98% 이상이다. 오래된 거래일 자료는 기존과 같이 집계에서 제외한다.
- 신규 상장 또는 기존 일봉의 조회 시작일 때문에 비교 종가가 없는 기간 수익률은 미제공으로 유지했다. 특히 2024-07-01의 1년 비교에 필요한 2023-06-30 일봉은 원래 복원 범위 밖이다. 이 경우 시총이 복원돼도 1년 수익률을 추정해 채우지 않는다.
- 정유·정유 지주, 석유화학, 발전 등의 검토 분류를 저장 아카이브와 거래대금 320거래일에 적용했다. 섹터 기록에는 원본 `source_sector`, `source_industry`도 보존한다.
- 거래대금 319거래일은 종가×거래량 추정에서 KRX `Amount` 실제 값으로 다시 정렬하고 상위 30개를 새로 선정했다. 이전 표와 비교해 219개 종목·일이 새로 상위 30위에 들어왔다. KOSPI·KOSDAQ 보통주·우선주를 포함하고 KONEX·ETF는 제외한다. 월별·연도별 누적 금액도 발행 과정에서 재집계한다.
- 2026-10-23은 공개 원본에 아직 없다. 해당 날짜의 기존 TradingView 저장값을 유지하고 분류만 보정했다. 최신 섹터 스냅샷도 정기 수집기가 소유하므로 현재 시총으로 과거 값을 추정해서 덮어쓰지 않았다.
- 10/22 정유·정유 지주 4종목은 **-5.9334688853%**다. 앞선 -6.003253%는 당시 저장된 TradingView 제공 시총을 사용한 값이고, 이번에는 해당 날짜의 KRX 확정 시총을 사용했다. 단순 평균 -5.103831%는 유지된다. 지주의 전체 시총을 사용하고, 기간 수익률에서 기초 시총을 역산하는 기존 추정 가중 산식도 유지한다.

## 원본·재현

[FinanceData/marcap](https://github.com/FinanceData/marcap)은 KRX 전종목 일별 자료를 제공한다. 이번에는 커밋 `eeed0817d1478597b738a3a6149c170ec7e3f4cb`의 `data/marcap-2024.parquet`, `data/marcap-2026.parquet`를 사용했다. 2024년 파일 SHA256은 `b0c38943e67637d5faf88429880092cf0f46a394be39860dd3bcd0b04231bccb`, 2026년은 `ecbba74c6ddacece3b0224de7776d3b4c3f561675c58abcef23816c8c3cada36`이다.

README에 남아 있는 과거 단위 설명에 의존하지 않고 모든 원본 행에서 **시총 = 당시 종가 × 당시 상장주식수**를 검증해 원화 단위임을 확인했다. 기존 조정 가격과 기간 수익률은 보존하고, 시총·거래대금만 날짜 일치 자료로 보완했다. 미래 주식 수를 소급 사용하지 않는다.

1. `python -m pip install --target data/tmp_korea_recalculation/deps pyarrow==26.0.0`
2. 고정 버전의 Parquet 파일과 URL·revision·SHA256을 담은 `.source.json`을 `data/tmp_korea_recalculation/source`에 준비한다.
3. `python scripts/recalculate_korea_history.py`로 단위·일자·원본 커버리지·순위를 검증한다.
4. `python scripts/recalculate_korea_history.py --apply`는 원본 447파일을 ZIP으로 백업한 뒤 검증된 교체 자료를 저장한다.
5. `node scripts/recalculate_sector_classification.mjs`는 공개 화면과 동일한 분류·수익률 함수를 사용해 5개 기간을 재계산한다.
6. `node scripts/refresh_sectors.mjs publish`, `python scripts/generate_turnover_data.py`로 일별·월별·연간 자료를 발행한다.

집계·매칭 결과는 `data/korea-history-recalculation/2026-10-25.json`, 날짜별 5개 기간의 업종 수익률 전체는 `rankings-2026-10-25.json.gz`에 보관했다. Parquet와 원본 ZIP은 Git에서 제외되는 로컬 작업 캐시에 있다. 모든 과거 원본은 이전 Git 커밋에서도 복구할 수 있다.

## 검증

- Python 206개, 스케줄러 42개, 운영 API 19개, 프런트 단위 테스트 26개(총 293개)가 통과했다. 타입 검사와 전체 `npm run build`, whitespace 검사도 통과했다.
- 새 과거 기록 브라우저 검사는 2024-07-01의 4개 정유 구성 종목, 5개 기간의 계산값/미제공 표시, 일별 확정 기준 안내, 기록 가격과 순위, 수동 새로고침 보존, 연간 합계, 1440/390px 화면을 검증했다.
