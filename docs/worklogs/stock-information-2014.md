# 2014년 데이터 확장

사용자는 2015년 운영 사이트·API 배포에 이어 2014년 데이터 확장을 요청했다. **2026-11-15 원본 수집·거래일·가격·실적·보존 감사를 통과했다. 운영 배포는 아직 완료하지 않았다.** 분리 작업본에서 최신 운영 자료 병합과 공개 파일·빌드·실제 화면 검증을 진행한다.

## 범위와 재개

- 6개 시장 신고가·거래대금, 종목 일봉·확정 실적, 국내 섹터·투자자 수급·같은 날짜 지수·신용잔고·반등, 코스피·금 선물 리플레이를 이전 연도와 같은 범위로 확장한다.
- 2015년 운영 배포 검증을 마친 뒤 `python data/tmp_2014/activate.py`로 검증한 운영 자료를 로컬에 병합하고 기존 자료를 보존한다. 이전 로컬 자료는 `pre-production-integration`, 코드 변경 전 원본은 `pre-activation-code`, 2014년 수집 직전 기준은 `baseline`에 보관한다.
- 수집은 `python scripts/run_2014.py <작업>`, 상태는 `python scripts/status_2014.py`로 확인한다. 실적과 일봉 작업 데이터베이스는 `data/tmp_2014`, `data/tmp_2014_history`에 분리한다. 진행 중인 수집기를 중복 실행하지 않는다.
- 확정 실적과 실제 거래만 사용한다. 미제공 분기·일봉을 추정하거나 네트워크 권한 거부·조회 실패를 자료 없음으로 확정하지 않는다. 가격 조정 기준이 다르면 원본 곡선을 별도로 보존한다.

## 거래일과 공식 일정

- 한국 245·미국 252·일본 244·중국 245·대만 248·유럽 256일, 합계 1,490거래일을 기준으로 실제 원본과 대조한다. 국내는 6월 4일 선거 휴장과 9월 10일 대체휴일을 포함한다.
- 대만은 7월 23일 태풍 휴장, **12월 27일 토요일 개장**을 포함한다. [TPEx의 2014년 일정](https://www.tpex.org.tw/storage/en-us/web/bulletin/trading_date/trading_date_103.htm)과 [증권업협회의 공식 2015년 1분기 기록](https://www.twsa.org.tw/B01/doc/104Q1.pdf)을 함께 사용한다. 토요일 실제 시세는 TWSE·TPEx 공식 원본과 인접 거래일 OHLC의 조정 비율을 검증한 후 반영한다.
- 준비 단계에서 12월 26·27·29일의 TWSE·TPEx 원본을 보존했다. 12월 27일 TWSE 898행·TPEx 2,671행의 실제 시세를 확인했다. 전체 표에는 보통주 외 상품도 있으므로 수집 대상 보통주와 동일 상장으로 대조해야 한다.
- **독립 검증 완료:** 12월 27일 복구와 12월 29·30·31일의 전일 종가·등락률·신고가 선별을 토요일 실제 거래까지 포함해 대조했다. 가격 곡선·원본 SHA256·토요일/월요일 실제 거래대금 상위 30개와 인접 거래일을 독립 검증했다. 전체 원본 재검사에서도 같은 검사를 다시 실행했다.
- [미국 일정](https://ir.theice.com/press/news-details/2013/NYSE-Euronext-Announces-2015-Holiday-Calendar-and-Early-Closings/default.aspx), [중국 공고](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20150912_3988725.shtml), [Euronext 일정](https://www.euronext.com/en/about/media/euronext-press-releases/nyse-euronext-announces-its-2014-holiday-calendar-and-early), [Xetra 일정](https://www.xetra.com/resource/blob/281576/967747fbc75fa120c2142e05d2e40711/data/trading-calendar-2014.pdf)의 원본·URL·SHA256을 `data/tmp_2014/sources`에 보존했다. 유럽 거래소별 휴장 차이를 유지한다.
- 대만의 구형 인증서 체인에서는 CA·호스트 검증을 유지하고 Python의 엄격한 체인 형식 검사만 호환 설정으로 전환한다.

## 완료 조건

공식 거래일 대조, 제공처 광역 누락 검사 및 독립 원본 복구, 종목별 일봉·실적 전수 감사, 기존 원본·가격·실적 보존 검사, 공개 파일과 원본의 일치 검사, 테스트·타입 검사·실제 브라우저·정적 빌드 검증을 마쳐야 수집 완료로 기록한다. 운영 배포 여부는 별도로 명시한다.

## 원본 수집·감사 결과 (2026-11-15)

- 신고가·거래대금은 각각 1,490거래일을 확인했다. 국내 섹터·투자자 수급·동일 날짜 지수·반등 245일, 신용잔고 246보고일을 확보했다.
- 상세 목록 25,160종목을 검사했다. 가격 시작 구간 확보 12,859개, 이후 상장 11,486개, 원본 제공 범위 제한 797개, 자료 부족 18개다. 제공처 미제공 분기와 일봉을 추정하지 않았다. 2014년 종료 확정 실적은 2,462종목·분기 8,531건이다.
- 주 가격 곡선 25,166개·56,711,563관측값에서 월봉·분기봉 혼입이 없음을 확인했다. 상세 목록 외에도 독립 원본 검증에 사용한 대만 종목 곡선을 보관한다.
- 대만 토요일 실제 거래 대상 1,363개 중 1,293개를 같은 종목·가격 조정 기준으로 검증했다. 미검증 70개는 제외 사유를 남겼다. 공식 휴장일의 제공처 값은 일반 차트에서 제외하지만 변경하지 않은 전체 원본을 별도로 보관한다. 정상 거래일 누락과 보관 원본 가격 변경은 감사에서 실패한다.
- 연결이 끊긴 유럽 5종목을 실제 제공처에서 다시 조회해 모두 복구했다. 보조 조회기의 통신 라이브러리 경로를 수정했고, 연결·접근 제한·의존성 오류를 미제공 데이터로 확정하지 않도록 했다. 근거는 `data/information-audit/2014/source-retries.json`이다.
- 기존 가격 53,433,422개·확정 실적 310,420행·원본 파일 37,627개·현재 종목 스냅샷 29개를 보존했다. 신용 2,922행·수급 2,912행, 반도체 114종목, 리플레이 13,318개 봉도 보존 검사를 통과했다.
- 분리 배포 검증에서는 가격·실적 보관 파일을 한 묶음씩 읽어 전수 감사의 메모리 사용을 줄인다. 종목 순서·확보 상태·비정상 가격 판정은 유지한다.
- 근거: `data/information-audit/2014/coverage.json`, `daily-frequency-audit.json`, `calendar-source-quality.json`, `taiwan-quality.json`, `preservation.json`. 최종 공개 파일 검증·배포 증빙은 별도로 추가한다.

## 배포 파일의 가격 압축

기존 2015년 사이트 묶음은 1 GiB 제한에 가까웠다. 2014년부터 배포 결과물의 가격 파일은 `stock-history-delta-v1` 형식으로 실제 날짜 간격을 저장하고 동일한 종가·조정 종가의 중복만 줄인다. 날짜·가격 정밀도·관측값·독립 원본 곡선은 복원 후 원본과 모두 같아야 한다. 날짜를 보간하거나 가격을 반올림하지 않는다. 원본과 공개 준비 파일은 기존 JSON 형식을 유지한다.

압축 파일은 `.delta-v1.json.gz` 주소를 사용한다. 새 클라이언트는 이 주소와 기존 gzip·JSON 주소를 순서대로 지원하며, 이전에 캐시된 클라이언트가 날짜 간격을 기존 날짜 문자열로 오인하지 않도록 한다. 반복 포장과 실제 클라이언트 복원을 검사하고, 최종 묶음 전체를 이전 연도 원본과 다시 대조한다.

## 분리 배포 검증 (2026-11-15, 운영 게시 전)

- 최신 운영에만 있던 4종목을 실제 제공처에서 추가 조회해 최종 상세 목록 25,164개를 검사했다. 2014년 시작 구간 12,859개·이후 상장 11,483개·제공 범위 제한 802개·자료 부족 20개다. 실제 이전 관측값과 모순되는 상장일은 적용하지 않았다.
- 병합 시 148종목의 원본 가격 시작점과 5종목의 확인된 상장일 정보를 보존했다. 오래된 실제 관측값 21,077개를 표시용 곡선에도 유지했다. 변경 전 주 가격 480,295개와 원본 보관본이 그대로 남아 있음을 검사했다. 증빙은 `historical-display-retention.json`이다.
- 공개 가격 57,477,905개(국내 대체 곡선 포함), 연속 가격 파일 25,168개와 실적 파일 25,165개를 원본과 대조했다. 현재 상세 목록과 원본 검증에 쓰는 추가 보관 종목 때문에 파일 수와 상세 목록 수는 다르다.
- TypeScript·API 27개·프런트엔드 54개 검사가 통과했다. 압축된 최종 묶음은 116,695파일·933,628,344바이트로 1 GiB 미만이다. 포장 과정에서 303 MiB를 줄였고 2014년 전체 파일 및 기존 2015·2016·2017년 파일의 복원·보존 대조를 통과했다. 최종 운영 갱신 시각 병합으로 메타데이터 바이트 수는 소폭 달라질 수 있다.
- 반도체 보관 원본이 저장소의 단일 파일 제한을 넘지 않도록 `data/semiconductor/preserved-snapshots/*.json.gz`에 분리했다. 주 파일은 175,695,540바이트에서 24,366,307바이트가 됐다. 압축 원본 114개·24,580,575바이트에서 보관본 1,220개·관측값 1,920,132개와 모든 메타데이터를 완전히 복원해 변경 전 데이터와 같음을 확인했다. 공개 원본·빌드 결과물의 바이트는 바꾸지 않았다.
- `semiconductor_provenance.py`는 압축 원본의 SHA256·종목·보관 개수를 검증하며, 체크섬이나 경로가 잘못되면 오류를 전달한다. 게시·수집기는 이 함수를 통해 원본을 복원하고 보관한다. 이후 연도 확장 시 기준 보관본에는 주 JSON과 참조된 `preserved-snapshots` 파일을 함께 보존해야 한다. 증빙은 `semiconductor-source-archive.json`이다.
- 실제 화면·운영 API·GitHub Pages 게시와 게시 후 검증은 다음 단계이며, 아직 운영 게시 완료로 기록하지 않는다.


## 최종 게시 전 검증 (2026-11-15)

- 가격 관측일을 보완한 최종 공개 가격은 57,477,905개다. 13,821종목의 원본 2014년 관측일과 대만 토요일 실제 가격 1,293개가 공개 주 곡선에 모두 남아 있음을 검증했다. 원본 달력을 대조해 1,454종목의 누락 관측일을 복구했다.
- Python 287개, API 27개, 프런트엔드 54개 검사와 TypeScript 검사를 통과했다. 최종 결과물 116,695파일·933,628,344바이트에 대해 2014·2015·2016·2017년 원본 대조 검사가 통과했다.
- 실제 로컬 서버에서 데이터, 8개 상세 화면, 6개 시장 달력, 2014년 실적, 수급, 모바일 화면과 원본 제공처 갱신 동작을 검증했다.
- 운영 API를 배포하고 실제 요청으로 확인했다. 버전은 `9a39848e-a586-455d-baeb-48e84b350930`이며 2014년 가격과 2014-01-02 코스피·코스닥 수급/지수가 확인됐다. 실시간 제공처가 미제공하는 과거 분기 실적은 추정하지 않고, 정적 사이트의 실제 공시 원본을 보존한다.
- 사이트 게시 완료는 GitHub Actions 성공과 실제 운영 화면 검사 후 별도 기록한다.
