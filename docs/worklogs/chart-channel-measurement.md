# 추세선 채널과 기준점 대비 등락률

- 추세선을 완성하면 해당 선을 자동 선택하고 평행선·중간선 설정을 바로 사용할 수 있다. 저장된 추세선도 선택 목록에서 고를 수 있다.
- 평행선 표시, 두 선 사이의 중간선 표시, 숫자로 간격 입력, 위·아래 반전을 제공한다. 평행선 중앙 손잡이와 선 자체를 끌어서 간격을 바꿀 수 있다. 중간선은 항상 정확히 두 선의 중앙이며 간격·표시 설정은 기존 종목별 저장 형식에 호환되게 추가했다.
- 이동 도구에서 빈 곳을 클릭하거나 ‘기준점 선택’을 사용해 실제 종가 날짜를 고정한다. 다른 날짜에 마우스를 올리거나 터치하면 가격 차이와 기준점 대비 등락률을 툴팁 및 차트 아래에 표시한다. 클릭한 세로 위치의 임의 가격을 기준으로 삼지 않는다.
- 기준점 다시 선택·해제, 방향키 조회 및 Enter로 기준 고정을 지원한다. 차트 확대·이동은 기준 날짜를 바꾸지 않는다. 그린 선 선택·드래그와 차트 이동도 기준점을 덮어쓰지 않는다.
- 수익률 비교 모드는 공통 기준으로 정규화한 값이므로 `(조회 수익률 - 기준 수익률) / (100 + 기준 수익률)`로 실제 가격 등락률을 계산하고, 단순 `%p` 차이와 구분한다. 비교 중인 각 종목의 결과를 따로 보여준다.
- 툴팁 위치를 화면 표시 전에 맞춰 포인터와 설명이 다른 위치에 나타나는 중간 프레임을 없앴다.

검증: 타입 검사와 프런트엔드 테스트 48개, 실제 종목 브라우저 조작·채널 기하/간격/반전/저장 복원·기준점 측정·모바일 터치·조회 실패 처리, 기존 툴팁 36건을 통과했다. [GitHub Pages 실행 41047369337](https://github.com/juyeop-dev/find_peer_stock/actions/runs/41047369337)의 빌드·공개와 운영 주소 검증도 통과했다.
