# 국내 섹터 상승률

요청한 표 형태로 `/sectors`에 국내 업종별 등락률·거래대금·시가총액·대표 종목을 추가했다. 기존 반도체 섹터 추이는 유지하고 서로 이동할 수 있게 연결했다.

## 데이터와 계산

- TradingView 국내 스캐너에서 보통주 전체를 한 번에 조회한다. `type=stock`, `subtype=common`, `price_conversion.to_symbol=true`를 지정해 우선주·ETF의 중복 시가총액과 외화 합산을 피한다.
- 원본 종목 코드·KRX 거래소·KOSPI/KOSDAQ 지수 편입을 교차 확인한다. 다른 시장·통화, 중복 종목, 미래 일자, 일부만 반환된 조회는 그대로 집계하지 않는다.
- 최초 스냅샷: 2026-10-19 거래일, 확인된 보통주 2,523개 중 최신 거래일 2,510개, 세부 업종 114개·대분류 20개. 다른 시장 또는 시장 미확인 103개를 제외했고 이전 거래일 13개는 최신 순위에서 제외했다. 시가총액 미제공 7개는 제공 수를 표시한다.
- 오늘·1주·1개월·3개월·1년의 제공 수익률을 동일 비중 평균한다. 누락은 0%로 취급하지 않는다. 거래대금과 시가총액은 원화 합계이며 기간을 바꿔도 거래대금은 해당 거래일 값이다. 대표 종목은 제공 시가총액 최상위 종목이다.
- TradingView 업종 분류를 한국어로 표시한다. 이미지의 서비스별 테마 구성과 같다고 주장하지 않는다.
- 원본 스냅샷 `data/sectors/index.json`, 발행 위치 `frontend/public/data/sectors/index.json`. `node scripts/refresh_sectors.mjs`로 수집하고 `publish` 인수로 네트워크 없이 복원한다.
- 기존 정상 빌드의 예약 갱신에 수집·저장을 연결했다. 수집 실패 시 저장 자료를 유지하고, 브라우저 새로고침은 운영 API `kind=sectors`로 전체 목록을 다시 조회한다. 더 오래된 정적 자료로 수동 갱신값을 덮지 않는다.

## 화면과 검증

- 거래대금순 기본 정렬, 등락률·시가총액·종목 수 정렬, 기간·시장·분류 선택, 업종/종목 검색을 지원한다.
- 섹터 선택 시 구성 종목을 표시하며, 대표/구성 종목은 기존 주가·확정 실적 상세 화면으로 연결한다. 상세에서 돌아오면 선택한 섹터·기간·시장·분류·검색어를 복원한다.
- 최신 API 운영 버전 `4e89fe23-c93f-4740-ab9d-67b49300e69f`의 전체 종목 실제 조회 HTTP 200을 확인했다.
- API 테스트 18개와 프런트 계산·연결 테스트 17개가 통과했다. 전체 프런트 빌드도 통과했다.
- 로컬 브라우저로 순위 정렬, 기간 선택, 종목명 검색, KOSDAQ 필터, 반도체 선택과 삼성전자 상세 이동/복귀, 실제 원본 조회, 실패 시 표 보존, 1440/900/320px 페이지 넘침을 확인했다.
- 지난 작업의 피어 모바일 배포 실행 39286562946은 게시 성공했다. 운영 상세 8개 경로의 2025년 차트·확정 실적·원본 새로고침·모바일 검사도 완료했다.

## 2026-10-21 캘린더·구성 종목·차트 개선

- `/sectors`에 월별 날짜 선택을 추가했다. Git에 남은 실제 스냅샷 534개를 검사해 10월 19·20·21일의 마지막 저장값을 복원했다. 원본이 없는 이전 날짜는 만들지 않는다.
- `data/sectors/daily/YYYY-MM-DD.json.gz`에 날짜별 기록을 보관하고 `calendar.json`을 발행한다. 최신 값은 기존 `index.json`으로 제공하며 거래일이 바뀔 때 직전 거래일의 마지막 스냅샷을 확정 보존한다. 같은 날 압축 파일을 5분마다 Git에 추가하는 비용을 피한다. 빌드와 예약 수집은 세 파일 종류를 모두 저장·발행한다.
- 날짜를 고르면 과거 가격·업종 구성·수익률·거래대금이 함께 바뀐다. 과거 기록 새로고침은 현재 시세로 기록을 바꾸지 않고 해당 기록을 다시 읽는다. 상세 기본 정보도 선택 날짜의 종목 구성과 가격을 유지한다.
- 섹터명/종목 수 클릭 시 선택 행 바로 아래에 전체 구성 종목이 펼쳐진다. 기본으로 목록을 열지 않으며 재클릭 또는 접기 버튼으로 닫는다. 검색·시장·기간과 상세 이동/복귀를 지원한다.
- 공통 `SemiconductorLineChart` 정보창은 실제 화면의 점 좌표에서 아래 12px에 배치한다. SVG 변환, 가로 스크롤, 크기 변경을 반영하고 가로로는 보이는 차트 영역 안에 유지한다. 원·외화·지수·조원 차트에 함께 적용했다. 키보드 방향키/Home/End도 지원한다.
- 아카이브·클라이언트·집계 단위 테스트 7개, 기존 운영 API 테스트 18개, 타입 검사와 프런트 빌드가 통과했다. 브라우저에서 과거 날짜와 실제 저장 가격·전체 종목 수·인라인 위치·접기·최신 복귀·기존 정렬/필터/원본 새로고침을 확인했다.
- 차트 브라우저 검사에서는 종목·피어·섹터·신용 잔고 4개 화면, 1440/900/390px, 각 3개 점의 총 36개 위치가 점 아래 12px 및 가로 표시 영역 조건을 통과했다. 섹터 페이지도 1440/900/320px 페이지 넘침 검사를 통과했다.
- 남은 단계: 변경분 push·게시 완료 후 운영 주소에서 두 브라우저 검사를 재실행한다. 기존 사용자 인덱스 4개는 작업 시작 시 자동 보관본으로 원복했다.
