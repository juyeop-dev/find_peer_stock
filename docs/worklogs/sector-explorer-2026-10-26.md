# 국내 전체 섹터 탐색 · 표 가독성

반도체 목록·추이 화면에서 다른 업종도 보고, 섹터 상승률의 구성 종목을 열로 정렬하고, PER·PBR의 숫자와 제목 정렬을 통일한다.

- 메뉴는 ‘섹터별 종목’(`/sector-stocks`)과 ‘섹터별 추이’(`/sector-trends`)다. 공통 섹터 선택기에서 국내 전체·대분류를 고른다. ‘반도체 · 세부 분류’ 선택은 기존 `/semiconductors`와 `/semiconductors/trends`의 세부 분류 화면을 연다.
- 국내 목록은 현재 검증된 KOSPI·KOSDAQ 보통주를 사용하며 업종·시장·종목명 검색, 기간 수익률과 가격·거래대금·시총 정렬을 제공한다. URL에 선택 상태를 보존하며 상세 화면에서 돌아와도 유지한다.
- 추이는 현재 구성 종목의 실제 조정 일봉으로 동일 비중 지수를 계산한다. 시작일 이전 기준값과 마지막 거래일 가격을 모두 가진 고정된 종목 집합을 사용하고, 계산 종목 수를 표시한다. 가격이 없는 날짜·신규 상장·통화 불일치로 임의의 값을 만들지 않는다. 현재 구성으로 계산하는 참고 추이이며 공식 지수가 아니다.
- 일봉은 선택한 그룹만 최대 6개씩 읽고 재사용한다. 그룹 변경 시 이전 요청을 중단한다. 새로고침은 목록 원본과 선택 그룹의 원본 일봉(동시 3개)을 다시 조회하며 실패한 종목은 확인한 이력을 유지한다.
- 섹터 상승률의 구성 종목 표는 종목·시장·가격·기간 등락률·거래대금·시총·분류 근거의 7개 열에서 방향을 바꿔 정렬한다. 누락값은 양방향 모두 마지막이다. 기존 가중 수익률과 정유·석유화학 검토 분류는 그대로 사용한다.
- 투자 지표 6개 열은 동일 폭과 우측 정렬, tabular 숫자, 읽기 쉬운 크기로 통일했다. PER·PBR은 배 단위, 배당수익률은 %, 소수점 둘째 자리로 표시한다. EPS와 52주 가격은 통화 단위를 분리한다. 손익·자산·현금흐름 표의 숫자 제목도 값과 같은 방향으로 맞췄다.

검증: 타입 검사·배포 빌드, 계산·보존·경로 단위 테스트 20개 통과. 실제 브라우저에서 금융 182종목의 전체 구성 일치, 26회 정렬 전환, 비반도체 일봉 차트와 기간 변경, 기존 반도체 화면, 상세 왕복, 투자 지표 제목/숫자 정렬과 1440/320px 폭, 원본 목록·일봉 재조회 HTTP200을 확인했다. 기존 섹터·KRX 과거자료·hover 브라우저 검사도 통과했다. 화면 캡처는 `data/tmp_2024/ui/`에 보관한다.
