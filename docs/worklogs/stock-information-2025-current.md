## 원본·검증 기록

- Yahoo 일봉과 TradingView의 같은 상장 종목 이력을 수집하며 종목 코드·자료원·통화를 보존한다. 신규 상장 전 날짜나 거래되지 않은 날짜를 임의로 채우지 않는다.
- Yahoo 확정 실적은 2025-01-01~현재와 2025년 단독 기간을 분리 요청한다. 최신 범위의 개수 제한으로 빠졌던 AAPL 2025-03-31 분기가 날짜를 나누면 실제 반환됨을 원본으로 확인했다.
- Naver 확정 실적은 `isConsensus=N`만 사용하고 억원 단위를 원 단위로 변환한다. 미국·유럽·일본·대만 등의 재무 수치에 원화 단위를 붙이지 않는다.
- 미국 일부 종목은 원본 `pro_name`과 종목명·USD 통화가 정확히 일치하지만 실제 무료 피드가 Cboe One(`source_id=BATS`, `full_name=BATS:동일종목`)으로 제공된다. 이 경우에 한해 대체 거래 자료로 명시한다. 다른 종목이나 해외 거래소로 바뀌면 거절한다. [TradingView 공식 설명](https://www.tradingview.com/support/solutions/43000473924-is-us-stock-market-data-free-by-default/).
- 세 상세 경로와 320~1440px 화면, 기본 1년/`2025년~` 선택, 실적 기간·통화, 새로고침 원본 요청과 실패 시 표 보존을 브라우저에서 확인했다.
- 운영 API에서 SK하이닉스·애플의 2025년 1분기~최신 발표 분기, LVMH의 2025년 연간/2026년 반기 실적과 현재 제공 시세를 확인했다.

- 전체 데이터와 코드가 main에 push됐고, 운영 API 버전은 `f3add9ee-03df-4b9d-bf82-b38242e3ad62`이다.

- 복구 시도 후 기존 스케줄러 원본을 재배포했고, 버전 `e4604049-8886-4045-876d-9a3cae73c0eb`, cron `*/5 * * * *` 복원을 확인했다. 임시 HTTP 경로나 새 비밀값을 만들지 않았다. 임시 GitHub workflow 정리 단계와 불필요한 actions 쓰기 권한도 제거했다.
- 공개 사이트의 신규 JS `index-DSzgHIAg.js`, `/data/stock-information/000660.KS.json` HTTP 200을 확인했다. 반도체·피어·6개 시장 대표 종목 8개에서 2025년 시작 가격과 확정 실적, 실제 information/history 원본 새로고침 HTTP 200을 확인했다. GitHub 실행 표시는 취소·대기가 혼재하므로 실제 홈페이지 응답으로 반영 여부를 검증했다.
