# 2017년 전체 데이터 갱신

요청 범위는 기존 연도 확장과 같은 6개 시장 신고가·거래대금, 개별 종목 차트·확정 실적, 국내 섹터·수급·동일 날짜 지수·신용잔고이며 일일 반등·코스피/금 선물 리플레이도 포함한다. 로컬 수집·전수 감사·공개 파일 생성·화면 검증과 정적 빌드를 완료했다. 운영 사이트·API에는 배포하지 않았다.

## 보존과 재개

- 기존 작업 폴더의 변경사항을 유지한다. `data/tmp_2017/baseline`에 기존 종목 정보·가격·반도체·수급·신용·개별 스냅샷을 백업했다. 일별 원본 27,086개의 SHA256을 `manifest.json`에 기록했다.
- 실적은 `data/tmp_2017/information.sqlite`, 가격은 `data/tmp_2017_history`에 별도로 저장한다. `python scripts/run_2017.py <작업 이름>`으로 재개하며 로그·PID·종료 상태는 `data/tmp_2017`에 기록한다. 실행 중인 작업을 중복 실행하지 않는다.
- KRX 금액·시총·저가 원본은 FinanceData/marcap revision `eeed0817d1478597b738a3a6149c170ec7e3f4cb`의 2017 Parquet이다. 원본 URL·조회 시각·SHA256은 `data/tmp_korea_recalculation/source/marcap-2017.source.json`에 저장한다.
- 확인한 확정 실적만 표시한다. 연간·누적 수치에서 미제공 분기를 추정하지 않는다. 서로 다른 조정 가격은 한 곡선에 섞지 않고 이전 원본을 스냅샷으로 보존한다.

## 거래일과 공식 근거

일정 기준 예상 거래일은 한국 243, 미국 251, 일본 247, 중국 244, 대만 246, 유럽 255일이다. 날짜와 근거는 `data/market-closures/2017.json`에 저장했다. 한국 임시공휴일·선거일·연말 휴장, 중국 명절 휴장과 유럽 거래소별 휴장을 포함한다. 실제 원본 거래일과 전수 대조한다.

- 대만 2월 18일·6월 3일·9월 30일은 [TPEx 공식 일정](https://www.tpex.org.tw/storage/en-us/web/bulletin/trading_date/trading_date_106.htm)에 명시된 토요일 개장일이다. 전후 실제 거래일 OHLC의 조정 비율을 검증하고 공식 TWSE·TPEx 시세로 복원한다.
- 중국은 [상하이거래소 2017년 휴장 공고](https://www.sse.com.cn/disclosure/announcement/general/c/c_20161222_4218613.shtml), 미국은 [Nasdaq 2017년 일정](https://www.nasdaq.net/PublicPages/assets/MyMID/2017_Trade_Calendar.pdf), 유럽은 [Euronext 2017년 일정](https://www.euronext.com/en/about/media/euronext-press-releases/euronext-announces-calendar-2017)을 기준으로 한다.

## 확인된 진행

- 국내 수급·동일 날짜 코스피/코스닥 지수 243거래일, 신용잔고 244보고일, 일일 반등 243거래일 추가.
- 반도체 114종목의 일봉을 확장하고 기존 관측을 보존했다.
- SEC 원본 확정 실적 2,806종목·12,596행을 수집하고 전체 실적 조회 후 적용했다.
- 신규 캘린더 종목 80개를 포함한 전체 24,954종목의 실적·가격 감사를 마쳤다. 확정 실적 2,806종목, 매출 2,328종목, 영업이익 2,178종목과 실제 분기 9,792건이다. 미제공 실적 22,148종목을 예외로 기록했다.
- 차트는 2017년 초부터 확인 14,750종목, 조회 시작일 이후 상장 9,264종목, 원본 범위 제한 925종목, 원본 미제공/두 점 미만 15종목이다. `coverage.json`, `coverage-results.json`, `coverage-exceptions.json`에 종목별 근거가 있다.
- 두 캘린더 각각 한국 243·미국 251·일본 247·중국 244·대만 246·유럽 255일, 합계 1,486일이다. 국내 섹터·수급 243일과 신용 244보고일을 전수 대조했다(`calendar-coverage.json`).
- 국내 섹터·거래대금 243일의 금액과 시총을 같은 날짜 KRX 실제 값으로 반영했다. 누락 원본 날짜는 0일이다.
- 대만 토요일 3일을 공식 TWSE·TPEx 시세와 전후 OHLC 조정 비율로 검증했다. 1,503종목의 차트에 실제 토요일 가격을 반영했다. 원본 기준이 맞지 않는 종목은 예외에 남기고 보간하지 않았다.
- 공식 휴장일에 제공처가 반환한 값은 2,959종목에서 주 곡선과 분리해 원본 스냅샷으로 보존했다. 기존 원본 보고서는 제거하지 않았다.
- 기존 일별 원본 27,086개 SHA256, 확정 실적 273,470행, 주 가격 관측 41,992,767개, 수급 2,165일·신용 2,172보고일, 반도체 114종목·리플레이 4,387개 관측 및 현재 종목 스냅샷 29개를 보존했다(`preservation.json`).
- 최종 Python 264개·API 26개·프런트엔드 78개 테스트 및 타입 검사 통과. 실제 원본 API에서 일봉 시작 `2016-12-20`, 2017년 실적 요청 범위, 2017-01-02 코스피 2,026.16·코스닥 632.04 및 동일 날짜 수급을 확인했다(`local-api.json`).
- 실제 Chromium에서 2017년 수급 캘린더·매수/매도/순매수·동일 날짜 지수·시장 합계·원본 재조회·실패 시 값 보존·1440/390/320px 검증을 통과했다. 캡처와 로그는 `data/tmp_2017/ui` 및 `investor-browser.log`에 있다.
- 일일 반등의 연도별 추가 수집은 `backfill-audit-2017.json`으로 별도 감사 기록을 남긴다. 기존 2018~2026년 고정 원본 전체도 재검증했으며 기존 보고서 추가·변경 없이 기존 범위 감사 기록을 재생성했다. 이후에도 한 연도 추가가 전체 범위 감사 파일을 덮지 않는다.

## 공개 묶음과 화면 검증

- 두 캘린더 × 6개 시장의 2017년 연간·월별 화면과 거래일 수, 대만 토요일을 포함한 월별 기록을 실제 Chromium에서 검증했다. 상세 8개 화면의 `2017년~` 차트와 확정 실적 또는 명시적인 미제공 안내, 신용잔고·원본 정보/가격 재조회·1440/320px 검증을 통과했다.
- 일일 반등은 2017/2018/2020/2025/2026의 실제 기록·날짜별 종목 연결·검색·전체 보고서 복사·기록된 0건·휴장/미등록 날짜·조회 실패 보존·1440/390/320px 검증을 통과했다.
- 호스팅 한도를 맞추기 위해 2026년 10월까지의 과거 일별 보고서 973개와 연도별 캘린더 집계 108개를 무손실 gzip으로 발행한다. 1,081개 파일의 복원 바이트·원본 SHA256과 최종 빌드의 압축 파일을 모두 대조했다. 기존 JSON 공개 사본은 별도 내용 해시 백업에 보존하며, 원본 저장소 보고서는 그대로 JSON이다. 11월의 최근 일별 JSON 경로와 기존 JSON 읽기 대체 경로를 유지했다.
- 수급 발행은 동일한 파일 본문을 다시 쓰지 않아 Windows의 불필요한 파일 교체를 피한다. 공개 수급 파일을 원본 전체와 대조했다.
- 최종 정적 묶음: `data/tmp_2017/site`, 108,984파일, **962.26 MiB**. 운영 경로 `/find_peer_stock/`로 빌드했다. 공개 2017년 보고서 2,972개·반도체 114종목·수급/신용·일일 반등·리플레이를 원본과 대조했다(`publication.json`).
- 현재 종목/피어 스냅샷 29개는 공개 파일 생성 뒤에도 바이트가 동일했다. 운영 사이트·API 배포는 수행하지 않았다.

수집 단계별 명령·종료 상태는 `data/tmp_2017/*.process.json`, 후속 단계별 상태는 `stage-*.json`에 있다. 모든 원본 수집과 후속 검증 단계는 완료했다. `python scripts/status_2017.py`로 확인할 수 있다.

## 운영 배포 결과 — 2026-11-12

- 사이트: https://juyeop-dev.github.io/find_peer_stock/ . [GitHub Pages 배포](https://github.com/juyeop-dev/find_peer_stock/actions/runs/43046182699)가 성공했고, 공개된 파일과 실제 Chrome 화면을 검증했다. 배포 커밋은 `1d51208a92935d341480d4ffe732a061f052295e`다.
- 운영 API도 배포했다. 버전은 `84e22e12-02fd-4a15-a0d9-dcf25f249953`이며, 2017년 가격·실적 요청과 2017-01-02 수급·지수를 실제 주소에서 확인했다.
- 운영 종목을 포함한 최종 감사 대상은 25,058개다. 2017년 확정 실적 제공 종목은 2,806개이며, 가격 이력은 2017년 포함 14,763개·이후 상장 9,321개·원본 범위 제한 952개·원본 미제공 또는 부족 22개다. 제공되지 않는 자료는 예외로 남겼다.
- 신고가·거래대금은 각각 1,486거래일, 국내 섹터·수급·반등은 243거래일, 신용잔고는 244보고일을 공개했다. 대만의 공식 토요일 거래일 3일도 확인했다. 반도체 114종목과 두 리플레이 시장의 2017년 시작 구간도 확인했다.
- 배포용 코드에서 Python 264개, API 26개, 프런트엔드 74개 테스트와 타입 검사가 통과했다. 운영 사이트의 연간·월간 캘린더, 상세 8개 경로, 실제 확정 실적 대조, 수급·반등 조회, 원본 재조회 및 모바일 화면 검증도 통과했다.
- 기존 운영 자료와 동시 수집 기록을 보존해 병합했다. 반도체 원본 가격 1,134,346개 관측치가 담긴 112종목의 이전 곡선은 `data/semiconductor/prior-snapshots-2017.json.gz`에 무손실 보관했다. 사용자의 다른 미배포 화면 변경은 이번 배포에 포함하지 않았다.
