# 2022년 데이터 확장

요청 범위: 2022-01-01~2022-12-31 전체 데이터. 6개 시장 신고가·거래대금 캘린더, 국내 섹터, 개별 종목 차트·확정 실적, 투자자 수급·동일 날짜 지수, 신용융자 잔고를 추가한다. 기존 2023년 이후 자료를 보존한다.

## 원본 및 복원 기준

- 한국 신고가는 Naver 조정 일봉과 거래량·52주 고가 및 전체 기간 고가를 대조한다. 한국 거래대금과 섹터의 과거 시가총액은 FinanceData/marcap의 KRX 일별 확정 금액으로 보완한다. 고정 revision `eeed0817d1478597b738a3a6149c170ec7e3f4cb`, 2022 Parquet SHA256 `179650f5d1bd6abecb03d1b8eddf5f59c5ca6a0402e7bf2578635790b9ca811c`를 사용한다.
- 미국·일본·대만·중국은 Yahoo 일봉 및 월봉을 대조한다. 해외 거래대금은 종가×거래량 추정치이며 실제 거래대금으로 표시하지 않는다.
- 유럽은 정확한 상장 코드·회사·통화를 검증한 TradingView 일봉과 전체 기간 월봉을 사용한다. 미확인 상장은 제외하고 부분 복원 안내를 유지한다. 거래대금은 날짜별 외환 일봉으로 USD 환산하며 GBX는 GBP/100로 계산한다.
- 휴장일은 `data/market-closures/2022.json`의 거래소 공지와 정부 공식 자료에 근거한다. 개별 유럽 거래소 휴장은 별도 원본 파일에서 관리하며, 일부 거래소만 휴장한 날을 유럽 전체 휴장으로 처리하지 않는다.
- 과거 섹터는 현재 분류로 당시 일봉을 재구성한다. 상장폐지 종목 전체를 보증하지 않는다. 당시 시가총액이 확인되지 않는 종목에 현재 시가총액을 대입하지 않는다.
- 과거 차트 캐시는 종목·통화와 겹치는 날짜의 가격을 검증한 후 이전 기간만 추가한다. 분할·배당 조정 관례가 다른 가격은 섞지 않는다. 이후 제공처 응답이 이전 날짜를 생략하면 기존 원본 스냅샷을 보존한다.
- 확정 실적은 보고 통화와 회계기간을 유지한다. 미제공 실적·분기는 추정하지 않는다. 원본이 연간 실적만 제공하면 분기로 나누지 않는다.

## 재현 및 재개

각 시장 캘린더의 기존 `backfill_*` 명령에 `--start 2022-01-01 --end 2022-12-31`를 사용한다. 유럽은 `--daily-bars 1500 --partial-history --universe-cache data/tmp_tradingview_chart/universe.json`를 함께 지정한다. 라이브 TradingView 수집에는 `scripts/requirements-chart-history.txt`의 의존성이 필요하다.

```powershell
node scripts/backfill_investors_2022.mjs
python scripts/backfill_credit_2022.py
python scripts/backfill_semiconductor_history_2022.py
python scripts/backfill_sector_history_2022.py
python scripts/recalculate_korea_history.py --start 2022-01-01 --end 2022-12-31 --audit-tag 2026-10-29-2022 --apply
python scripts/backfill_stock_information_2022.py collect --workers 12
python scripts/backfill_stock_information_2022.py export
python scripts/extend_stock_history_2022.py
python scripts/refresh_stock_information_history.py --state-dir data/tmp_2022_history
python scripts/audit_calendar_2022.py
python scripts/audit_stock_information_2022.py
```

실적 DB는 `data/tmp_2022/information.sqlite`, 일봉 DB는 `data/tmp_2022_history/{information,history}.sqlite`다. 초기 상태는 현재 발행된 압축 원본에서 가져오며 과거 작업 DB로 되돌리지 않는다. 수집 전 자료의 해시와 원본 팩은 `data/tmp_2022/baseline`에 보관한다.

## 수집 결과

- 신고가·거래대금 각각 **1,486개** 일별 리포트: 한국 246일, 미국 251일, 일본 244일, 대만 246일, 중국 242일, 유럽 257일. 모든 평일을 실제 기록 또는 공식 휴장 일정과 대조했다. 유럽은 거래소별 휴장도 대조하며 휴장 거래소의 종목을 제외한다.
- 국내 섹터 246일, 투자자 수급·동일 날짜 지수 246일, KOFIA 신용융자 잔고 247개 보고일을 추가했다. 섹터와 한국 거래대금의 246일 모두 당시 KRX 금액으로 보완했고 누락 원본 날짜는 없다.
- 최종 **23,557종목 전수 조회**를 완료했다. 현재 정보·2022년 실적·일봉 단계의 `next`가 모두 `null`이다. 2022년 초를 포함하는 주가 19,417종목, 이후 상장 확인 3,594종목, 원본 범위 제한 531종목, 두 점 미만/미제공 18종목이다.
- 2022년 종료 확정 실적은 **20,462종목**, 매출 20,407종목, 영업이익 19,135종목이다. 미제공 3,095종목은 예외 목록에 남겼다. 확인된 2022년 분기 실적은 0건이며 연간 실적을 분기로 나누지 않았다.
- 유럽은 5,669개 스캐너 목록 중 일봉이 검증된 5,662종목을 사용했다. 미확인 6개 상장과 원본에서 주식이 아닌 것으로 확인된 1개는 제외했다. 신고가 후보 1,761종목의 전체 기간 월봉을 추가 검증했다. 검증되지 않은 다른 상장으로 치환하지 않는다.
- 별도 반도체 102종목의 가격을 원본에서 검증했다. 99종목은 가격이 일치하는 이전 구간만 추가했고, 3종목은 조정 방식이 바뀐 원본을 하나의 시계열로 쓰면서 이전 원본을 별도 스냅샷으로 보존했다. 이후 상장 종목의 2022년 가격을 만들어 넣지 않는다.

## 기존 자료 보존

기존 일별 신고가·거래대금·섹터 원본 **8,799개**의 SHA256이 동일하다. 투자자 수급 930일과 신용 잔고 932개 기존 보고일의 모든 값, 기존 22,821종목에 저장된 확정 실적 **175,924건**도 동일함을 확인했다. 반도체 102종목의 기존 실적·지표·분류와 이전 가격을 보존했다.

기존 22,817개 가격 이력의 모든 원본 값을 현재 시계열 또는 이전 스냅샷에서 대조했다. 원본 재조회 과정에서 생략되거나 조정된 가격 94,869점을 1,847종목의 별도 원본 스냅샷으로 보완했다. 서로 다른 조정 가격을 한 곡선에 합치지 않는다. 이후 자동 수집도 생략된 날짜뿐 아니라 수정된 이전 값까지 보존한다. 검증 근거는 `price-preservation.json`과 `preservation.json`에 있다.

## 검증 상태

Python 214개, 원본 조회 API 24개, 프런트엔드 32개 테스트와 타입 검사를 통과했다. 2022년 전체 캘린더 감사 및 기존 2023년 감사도 통과했다. 실제 제공처를 호출하는 로컬 API에서 TSMC의 2022년 확정 실적·2021-12-20부터의 일봉, 2022-01-03 코스피·코스닥 수급·동일 날짜 지수를 확인했다. `local-api.json`에 결과를 기록했다.

브라우저에서 6개 시장의 2022년 월별·연간 캘린더, 8개 종목 상세의 2022년 차트·실적, 과거 섹터와 신용 잔고, 수급·지수의 정확한 금액·날짜·휴장·재조회·실패 시 보존 및 320px 화면을 확인했다. 검증은 로컬 사이트와 로컬 API에서 수행했다.

운영 경로 `/find_peer_stock/`와 운영 API 주소로 최종 정적 파일을 `frontend/dist`에 준비했다. **909,044,529바이트(866.93 MiB), 86,000파일**이며 기존 기록을 포함하고도 1 GiB 범위 안이다. 로컬 API 주소가 없고 `404.html`과 `index.html`이 같음을 확인했다. 상세는 `release.json`에 있다. **운영 배포는 아직 수행하지 않았다.**

최종 운영 경로의 로컬 미리보기에서도 한글 IME 검색 3개 경로를 검증했다.

## 승인 후 운영 반영

사용자가 사이트와 API 배포를 모두 승인했다. 원본 조회 API 버전 `e7774ff0-4068-439b-8b39-89f9eb094250`을 배포했고, 실제 운영 주소에서 TSMC의 2022년 확정 실적·일봉 및 2022-01-03 국내 수급·지수를 확인했다. 결과는 `production-api.json`에 있다. 원격의 최신 자동 갱신 자료를 병합한 뒤 사이트를 공개한다.

원격 자동 갱신 병합 후 추가 10종목도 조회했다. 최종 목록은 **23,567종목**, 2022년 확정 실적 20,466종목, 2022년 초를 포함하는 일봉 19,432종목이다. 이후 상장 3,594종목, 원본 범위 제한 523종목, 두 점 미만/미제공 18종목은 예외로 구분한다. 분기 추정은 하지 않았다.

최신 원격 원본의 시세·실적·수급·지수·신용 잔고를 병합했으며 2022년 확정 실적은 모두 유지했다. 일봉은 통화와 겹치는 과거 가격을 대조해 이을 수 있는 자료만 합쳤다. 조정 관례가 다른 58개 시계열은 2022년을 포함하는 검증 시계열을 유지하고 최신 원본도 별도 스냅샷으로 보존했다. 현재가는 최신 정보에서 별도로 유지한다. 병합 후에도 Python 214개와 2022년 캘린더 감사를 통과했다.

병합 후 운영 설정으로 다시 빌드한 최종 산출물은 926,431,059바이트(883.51 MiB), 82,550파일이다.
