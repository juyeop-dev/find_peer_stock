# 한글 검색 조합 중복 수정

섹터별 종목·추이와 섹터 상승률 검색에서 한글 조합 입력마다 URL의 q를 갱신해 React Router가 입력값을 다시 쓰고 IME 조합을 끊었다. Chromium의 실제 `Input.imeSetComposition`으로 `ㅎ → 하 → 한`, `ㅁ → 미`를 입력했을 때 수정 전 `ㅎ하한한ㅁ미미`가 표시되는 것을 재현했다.

`ImeSearchInput`이 조합 중인 입력값을 로컬에 유지하고 조합 완료 시 검색값을 전달한다. `compositionend` 이후의 중복 change 통지는 한 번만 전달하며, 늦게 도착한 기존 URL 갱신 응답이 새 입력값이나 커서를 덮어쓰지 않도록 구분한다. 외부 URL 변경과 페이지 재진입 시의 검색어 복원은 유지한다. 영문 입력·붙여넣기·삭제는 일반 입력대로 검색에 반영한다.

적용 화면: `/sector-stocks`, `/sector-trends`, `/sectors`. 검색 알고리즘·종목 데이터·차트 계산은 변경하지 않았다.

검증: 세 경로의 실제 IME 입력으로 `한미`와 검색 결과, 조합 중 q 유지, 중간 글자 삽입과 커서, 조합 취소, 비우기, 빠른 영문 입력, Backspace, 외부 URL 변경과 복원을 확인했다. CI에서도 프로덕션 경로의 정적 빌드를 열어 같은 Chromium 회귀 검사를 실행한다. 회귀 검사는 거래 정지·공표 시각 등 외부 상황에 영향을 받지 않도록 해당 브라우저의 섹터 데이터 응답만 고정 fixture로 대체하며 운영 데이터를 바꾸지 않는다.

타입 검사·배포 빌드와 실제 데이터의 기존 섹터 브라우저 검사(검색·정렬·시장 전환·상세 왕복·과거 날짜·원본 재조회·모바일)도 통과했다. 별도의 전체 탐색 검사에서는 원본 일봉 재조회 후 추이 종료 대기가 실패했다. 점검 시 시장 기준일은 2026-10-26, KB금융(105560.KS)의 Yahoo 원본 일봉 마지막 날짜는 2026-10-23임을 확인했으며, 이 검사는 통과로 기록하지 않았다.

push·배포 및 운영 검증 결과는 완료 후 추가한다.
