# 2024년 전체 기록 갱신

범위: 2024-01-01~2024-12-31. 기존 하반기 및 2025년 이후 기록을 보존하고 상반기를 추가했다. 시작 원격 커밋 b626adcc6, 시작 작업 트리는 깨끗했다.

## 완료한 자료

- 6개 시장 신고가·거래대금 각각 1,482개 일별 리포트. 상반기 726개씩 추가했다. 한국 244일, 미국 252일, 일본 245일, 대만 242일, 중국 242일, 유럽 257일이다. 모든 평일을 거래 기록 또는 공식 휴장일과 대조했다. 대만 태풍 휴장 5일도 구분했다.
- 상반기 섹터 121개 거래일 추가. 기존 하반기 교정 자료는 변경하지 않았다. 고정 revision·SHA의 KRX/FinanceData 원본으로 당시 시가총액 및 실제 일별 거래대금을 보완했다. 감사: data/korea-history-recalculation/2026-10-26-2024-h1.json.
- 21,085종목 전수 점검. 18,444종목은 2024년 시작을 포함하는 주가 이력, 2,094종목은 이후 상장 확인, 521종목은 제공 범위 제한, 26종목은 유효한 이력 미확인이다. 빈 기간에 가격을 만들지 않았다.
- 2024년 종료 회계기간 확정 실적 18,704종목, 매출 18,564종목, 영업이익 17,423종목을 확인했다. 미제공 2,381종목은 별도 예외 목록에 남겼다. 제공된 2024년 실적은 연간이며 과거 분기 원본은 확인하지 못했다. 연간 실적을 분기별로 나누거나 추정하지 않았다.
- 감사와 종목 순서는 data/information-audit/2024/coverage*.json, data/information-audit/results.jsonl 및 progress.json에 저장했다. 모든 단계 next=null, checked=21,085이다.

## 자료의 한계

- 한국 거래대금은 실제 KRX 일별 Amount다. 해외 과거 거래대금은 명시한 종가×거래량 추정치다. 유럽은 거래일별 FX로 USD 환산하고 GBX는 GBP로 나눴다.
- 과거 섹터는 현재 사업 분류·현재 확인되는 종목으로 재구성했으며 당시 공식 구성 전체가 아니다. 시가총액은 당시 KRX 값이며 현재 시가총액으로 대체하지 않았다. 기존 정유 지주 등 검토 분류와 가중 방식은 보존했다.
- EURONEXT:MHM은 회사명 검증 불일치, XETR:1T4는 차트 없음으로 상반기 유럽 부분 복원에서 제외했다. 검증되지 않은 다른 회사에 매핑하지 않았다. 일반 엄격 검증은 유지하며 --partial-history에서만 제외 내역을 공개한다.
- SEC 공식 매핑·2024Q3 bulk·companyfacts 조회는 HTTP403을 반환했다. 차단을 우회하거나 2024년 분기를 추정하지 않았다.

## 구현과 재개

- 일봉 요청은 2023-12-20부터, 실적 회계기간은 2024-01-01부터다. 주가 차트에 2024년~ 선택을 추가했다. 기존 2024년 하반기~·2025년~ 선택도 유지한다.
- 운영 API 배포 버전: 7fec298a-8159-4804-a081-2868cba6e163. 화면·수집기·일일 자동화도 전체 2024년 범위를 사용한다.
- 독립 상태: data/tmp_2024/{information,history}.sqlite. 기존 다른 수집 DB로 내보내지 않는다.
- 재개 명령: python scripts/backfill_stock_information_2024.py collect, 이어서 export. 주가는 python scripts/refresh_stock_information_history.py --state-dir data/tmp_2024. 미확인 이력에는 날짜 지정 조회와 일시 오류 재시도를 한 번씩 완료했다.
- 출력 JSON 공백만 줄여 가격 정밀도·자료원·기록을 보존했다. 배포 빌드 968.6 MiB로 Pages 1 GiB 제한 이내다.
