# 2018년 데이터 확장

요청 범위는 기존 2019년 확장과 같은 신고가·거래대금 6개 시장, 개별 종목 가격·확정 실적, 국내 섹터·투자자 수급·동일 날짜 지수·신용잔고다.

## 기존 자료 보존

- 작업 폴더는 기존 저장소를 사용한다. 기존 차트·리플레이 변경을 보존한다.
- 최초 변경 전 원본 SHA256과 실적·가격·반도체·수급·신용·개별 종목 스냅샷은 `data/tmp_2018/baseline`에 저장했다. 기존 일별 자료를 덮어쓰지 않는다.
- 실적은 `data/tmp_2018/information.sqlite`, 가격은 `data/tmp_2018_history`에서 재개한다. 각 작업의 PID·명령·시작 시각과 출력은 `data/tmp_2018/*.process.json`, `*.log`에 저장한다.
- 실행: `python scripts/run_2018.py <작업 이름>`. 같은 작업이 실행 중일 때 중복 실행하지 않는다.

## 날짜와 원본

- 공식 캘린더 예상 거래일은 한국 244, 미국 251, 일본 245, 중국 243, 대만 247, 유럽 256일이다. 출처와 날짜는 `data/market-closures/2018.json`에 기록한다.
- 대만 3월 31일·12월 22일은 실제 토요일 개장일이다. 평일만 수집하던 기존 도구를 확장했다. [TWSE 2018 공식 일정](https://www.twse.com.tw/staticFiles/product/publication/0001002657.pdf), [대만 지수회사 개장 안내](https://taiwanindex.com.tw/news/101).
- 미국 12월 5일 특별 휴장과 중국 12월 31일 휴장을 포함한다. 미제공 가격을 휴장·보간 값으로 대체하지 않는다.
- 국내 금액·시총은 고정 revision `eeed0817d1478597b738a3a6149c170ec7e3f4cb`의 FinanceData/marcap 2018 Parquet을 사용한다. 출처·SHA256은 `data/tmp_korea_recalculation/source/marcap-2018.source.json`에 저장한다.
- SEC 실적은 회사·거래소·CIK·USD 단위·실제 회계기간을 검증한다. 연간·누적 실적에서 분기를 추정하지 않는다.

## 진행

- 신용잔고 245개 실제 보고일 수집 완료.
- 국내 수급과 동일 날짜 코스피·코스닥 지수 244거래일 수집 완료.
- 반도체 102종목의 가격을 2018년부터 확장했다. 조정 기준이 다른 기존 곡선은 원본 스냅샷으로 보존했다.
- SEC 2,948종목·13,116행의 확정 원본을 확보했다. 전체 실적 수집 종료 후 적용한다.
- 신고가·거래대금 두 캘린더 각각 1,486거래일을 전수 검증했다. 한국 244·미국 251·일본 245·중국 243·대만 247·유럽 256일이다. 국내 섹터의 거래대금·시총은 같은 날짜 KRX 확정 값으로 반영했다.
- 대만 두 토요일은 TradingView에서도 빠져 있었다. TWSE·TPEx 공식 시세표를 확보했고 3월 31일 1,506종목, 12월 22일 1,470종목의 전후 거래일 OHLC 전체가 같은 조정 비율인지 검증했다. 확인된 1,561종목의 차트에 실제 토요일 가격을 추가했다. 조정 기준 불일치·주변 거래일 미제공 종목은 예외에 기록한다. 토요일 거래대금은 종가×거래량 추정치가 아닌 공식 실제 거래금액을 사용한다.
- 일본 제공처가 휴장일에 반환한 이월·거래량 0 값으로 만들어진 신규 보고서 32개를 공식 일정과 대조해 제외했다. 기존 원본에는 손대지 않았다. 가격 이력의 같은 날짜 값도 원본 보존 곡선에 유지하고 정규장 차트에서는 제외한다.
- 전체 24,873종목 조회와 전수 감사를 마쳤다. 확정 실적 2,948종목, 매출 2,403종목, 영업이익 2,290종목, 실제 분기 10,190건이다. 실적 미제공 21,925종목은 예외 목록에 정리했다. 가격은 2018년 초부터 확인 15,671종목, 이후 상장 7,383종목, 원본 범위 제한 1,804종목, 미제공 15종목이다. 다음 명령으로 재개·검증할 수 있다.

```powershell
python scripts/run_2018.py financial-finalize
python scripts/run_2018.py korea-finalize
python scripts/run_2018.py europe-turnover
python scripts/extend_stock_history_2018.py
python scripts/refresh_stock_information_history.py --state-dir data/tmp_2018_history --import-europe-cache --extend-to-start
python scripts/complete_history_audit_2018.py
python scripts/finalize_histories_2018.py
python scripts/audit_calendar_2018.py
python scripts/audit_stock_information_2018.py
python scripts/audit_preservation_2018.py
```

화면·API의 시작일과 `2018년~` 선택을 추가했다. API 26개 테스트와 프런트엔드 타입 검사를 통과했다. 수집 중이며 배포 완료를 의미하지 않는다.

## 보존 검사와 배포 상태

- 기존 원본 21,701개의 SHA256, 확정 실적 260,039행, 주 가격 관측 38,105,411개, 수급 1,921일·신용 1,927개 보고일과 반도체 102종목을 보존했다(`preservation.json`).
- Python 241개·API 26개·프런트엔드 63개 테스트와 타입 검사를 통과했다. 실제 원본 조회로 2017-12-20부터의 일봉·2018년 실적 범위·2018-01-02 수급과 동일 날짜 지수 2,479.65 / 812.45를 확인했다. 실적 원본의 미제공 응답은 저장된 SEC 실적을 지우지 않는다.
- 로컬 검토·빌드용 작업 폴더: `data/tmp_2018/deploy-worktree`, 기준 `f7fd17b5620e46815a037422d686b830202ac92b`. 최신 운영 시세·지수·섹터·수급 자료를 유지하며 2018년 값을 병합한다.
- 운영 API 배포 실행은 자동 승인 심사에서 거절됐다. 데이터 업데이트 요청에 공유 운영 서비스 변경 권한이 명시되지 않았다는 이유다. API와 사이트는 아직 배포하지 않았으며 사용자의 명시적 승인 후에만 배포한다.

## 로컬 화면 검증 완료

- 신고가·거래대금 두 캘린더 × 6개 시장, 상세 화면 8개, `2018년~` 차트, 확정 실적 또는 미제공 안내, 신용잔고, 실제 원본 정보·가격 재조회와 1440/320px 검증을 통과했다.
- 2018-01-02 수급·두 지수·시장 합계·실패 시 기존 값 보존·1440/390/320px 검증을 통과했다. 원래 작업 폴더의 현재 시세·피어 스냅샷 29개도 그대로 보존했다.
- 배포 용량 한도를 맞추기 위해 기존 무손실 gzip 발행을 2026년 상반기까지 확장했다. 1,440개 보고서의 복원 바이트가 원래와 정확히 같은지 확인했다. 보존용 반도체 과거 곡선은 저장소에 유지하고 공개 묶음에는 102종목의 완전한 주 곡선을 발행한다.
- 로컬 산출물 99,622파일, 약 949 MiB. 공개 2018년 보고서 2,972개와 반도체 102종목의 주 곡선을 생성 원본과 전수 대조했다(`publication.json`).
