# 2013년 데이터 추가

2026-11-28 로컬 작업본에 2013년 자료를 반영했다. 각 시장의 신고가와 거래대금 기록을 거래소 달력과 대조했다.

| 시장 | 거래일 |
| --- | ---: |
| 한국 | 247 |
| 미국 | 252 |
| 일본 | 245 |
| 중국 | 238 |
| 대만 | 246 |
| 유럽 | 256 |
| 합계 | 1,484 |

- 국내 섹터, 일일 반등, 투자자 수급과 두 시장 지수는 각각 247거래일이다. 거래대금과 반등은 당시 상장 종목의 KRX 일별 원본을 사용했다. 섹터는 현재 분류 기준을 적용했다. [KRX 시가총액·거래 원본 미러](https://github.com/FinanceData/marcap/blob/eeed0817d1478597b738a3a6149c170ec7e3f4cb/data/marcap-2013.parquet)
- 대만의 2월 23일과 9월 14일은 양 거래소가 확인한 토요일 실제 거래일이다. 거래대금은 거래소 원본을, 신고가는 전후 거래일의 가격 조정 기준이 일치하는 이력을 사용했다. [대만 금융감독위원회 거래 일정](https://www.fsc.gov.tw/fckdowndoc?file=%2FNewsletter_106_from_SFB_of_FSC%2C_TAIWAN%28_R_O_C_%29.pdf&flag=doc)
- 신용융자 248보고일을 추가했다. FreeSIS 직접 조회가 HTML을 반환하여 고정 버전 미러를 사용했다. 기존 2014년 246보고일에서 전체·코스피·코스닥 잔고가 모두 일치했다. [FreeSIS 미러](https://github.com/HighRiskLowYield/tscs-korea-tracker/blob/09dad08fce5b48e24d1785ae96b841564924b6ba/kofia_credit_components_daily.csv)
- 미국 2,366종목의 확정 실적 10,493건을 반영했다. 실적은 같은 공시의 보고 기간과 통화를 유지했다. [SEC EDGAR XBRL](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)
- 10,390종목의 일봉을 보강했다. 2013년 관측값이 있는 일봉은 총 12,831종목이다. 이 중 일부는 공급처가 제공한 기간만 포함한다. 서로 겹치는 거래일의 가격 기준을 검증해 기존 관측값을 보존했다. 필요할 때 검증된 2014년 배포 자료를 비교 기준으로 사용했다. 반도체 목록의 67종목에도 2013년 일봉이 있다.
- 리플레이는 코스피 247개, 금 선물 252개 일봉을 추가했다. 해외 거래대금에는 종가와 거래량을 이용한 추정치가 포함되며 유럽은 해당 날짜 환율을 적용했다.

시장 리플레이는 2026년 1월 1일부터 한국 시간 기준 오늘까지 코스피와 금 연속선물을 겹쳐 연다. 첫 공통 거래일의 수정종가를 0%로 두고 양쪽에 일봉이 있는 날짜를 비교한다. 2026년 11월 28일 기준 두 시장의 최신 확보 일봉은 11월 27일이다.

## 검증

- 2013년 원본과 공개 형식의 날짜·종목·가격·금액·공시를 [전체 대조](../../data/information-audit/2013/local-validation.json)했다. [일봉 보강 집계](../../data/information-audit/2013/price-collection.json)도 저장했다.
- Python 287개, API 29개, 프런트엔드 94개 테스트와 TypeScript 검사를 통과했다. 로컬 API의 실제 2013년 첫 거래일과 마지막 거래일 수급·지수 조회도 성공했다.
- 브라우저에서 2013년 수급과 휴장일, 신용융자 기간, 대만 토요일 신고가·거래대금, 국내 반등과 섹터, Apple의 실적, Apple과 삼성전자 일봉을 확인했다.
- 로컬 사이트 빌드는 123,550개 파일, 594,267,183바이트다. 압축된 자료에서도 2013년 전체 대조를 통과했다.
