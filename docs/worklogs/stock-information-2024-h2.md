# 2024년 하반기 주식 기록 확장

2024-07-01~2024-12-31 기록을 추가하면서 기존 2025~2026 자료를 유지했다. 시작 main은 f3ef6b970, 시작 pull autostash는 141169e3c이다.

## 수집 결과

- 신고가·거래대금: 한국 123일, 미국 128일, 일본 125일, 대만 125일, 중국 125일, 유럽 130일. 각각 총 756개 일별 리포트 추가.
- 국내 섹터: 123개 거래일을 실제 Naver 조정 일봉으로 재구성. 당시 일봉이 확인된 종목에 현재 업종 분류를 적용했다는 안내를 표시하며, 당시 시가총액은 null이다.
- 개별 페이지 명단: 19,544개. 캘린더·반도체·비교 종목과 섹터 전용 종목까지 포함하고 모든 종목을 명단 순서로 조회했다.
- 2024년 하반기까지 주가 확보 17,315개, 이후 상장 확인 1,730개, 제공 이력 부족 476개, 일봉 2개 미만/미제공 23개. 실제 제공일만 저장한다.
- 2024년 확정 실적 제공 14,298개 종목. 매출 제공 14,176개, 영업이익 제공 13,169개. 미제공 5,246개는 값을 추정하지 않았다.
- Yahoo의 과거 분기 보존 제한으로 2024년 분기 실적은 확보되지 않았다. 확보한 FY2024 연간 실적은 해당 회계연도 전체이며 하반기만의 합계가 아니다. 화면에 연간 1건·분기 0건 등 실제 제공 범위를 명시한다.
- 자산·차입금·영업현금흐름·잉여현금흐름은 확정 원문이 제공하는 항목을 함께 저장한다. 원문 통화를 유지한다.

## 화면과 갱신

- 모든 공통 개별 차트에 `2024년 하반기~` 기간 추가. 기본 1년 및 기존 2025년 선택 유지.
- 짧은 인라인 주가가 있어도 더 긴 저장 이력을 조회해 과거 기록이 가려지지 않게 했다.
- 정적/일일 수집/운영 API의 주가 요청 시작일을 2024년 6월(7월 초 비교 기준일 포함)로 확장하고, 확정 실적 필터는 2024-07-01로 변경했다.
- 수동 새로고침도 FY2024 확정 실적과 제공 범위를 반환한다. 서로 다른 통화나 제공처의 항목을 한 재무제표로 임의 합성하지 않는다.
- 가격·실적은 제공처 최신 조회 자료이고, 캘린더 기본 정보는 선택한 과거 기록이라는 구분을 유지한다. 2024년 당시 공시로 알려져 있던 정보만을 재현하는 시점 백테스트 데이터는 아니다.

## 복원 범위와 출처

- 신고가는 실제 당시 일봉 고가와 직전 52주·전체 기간 월봉을 검증했다. 현재 조회 가능한 상장 종목 기준으로 상장폐지 종목 전체를 보증하지 않는다.
- 과거 거래대금은 종가×거래량 추정치이며 실제 체결금액 합계와 다르다. 유럽은 실제 당일 환율로 USD 환산하고 GBX는 GBP의 1/100로 계산한다.
- 유럽 2024년은 일부 거래소가 원래 상장 코드의 오래된 일봉을 제공하지 않는다. 기본 전체 검증은 실패했으며, 별도의 `--partial-history` 옵션으로 **부분 복원**임을 명시한 자료만 발행했다. 순위가 시장 전체와 다를 수 있다는 경고와 거래소별 확인 종목 수를 표시한다. 기존 수집기의 기본 검증 기준은 유지했다.
- EURONEXT의 Yahoo 상장 코드는 회사명·거래소·표시 통화를 대조하고 정확히 하나만 검증된 경우 사용했다. 검증 기록은 `data/information-audit/2024-h2/listing-mappings.json`에 남긴다.
- 통화 없는 주가 자료 LSE:TGE, LSE:KAKU는 같은 거래소의 통화가 확인된 TradingView 일봉으로 교체했다. 새 수집에서는 통화 없는 자료를 거절한다.
