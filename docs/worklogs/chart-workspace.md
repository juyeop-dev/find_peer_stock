# 종목 차트 비교와 그리기

모든 종목 상세 화면의 공통 주가 차트에 분석 도구를 추가했다.

- 종목명·티커로 최대 3개 비교 종목을 추가하거나 제거한다. 전체 수집 종목 목록은 기존 정보 발행 단계에서 작은 압축 검색 목록으로 함께 생성한다.
- 비교는 모든 선택 종목에 실제 관측이 있는 거래일의 조정 종가를 공통 시작일 0%로 환산한다. 조정 종가 미제공 시 해당 종가를 사용한다. 각 통화 기준이며 환율 수익률은 포함하지 않는다. 휴장일 값을 이월하거나 보간하지 않는다.
- 가격 모드의 20·60·120거래일 단순 이동평균은 선택 기간 이전의 실제 이력으로 계산을 준비한다.
- 추세선은 두 점, 수평선·수직선은 한 점을 선택해 그린다. 이동 도구에서 선을 선택하고 선 전체 또는 끝점을 끌어 편집한다. 색상, 선택 삭제, 전체 삭제, 실행 취소를 지원한다.
- 선은 종목·통화·가격/수익률 좌표별로 브라우저에 저장한다. 수익률 선은 비교 조합과 기준일도 구분한다. 저장 공간이 차단되면 현재 화면만 유지하며 안내한다. 원본 가격 데이터는 변경하지 않는다.
- 휠과 버튼 확대·축소, 드래그 이동, 날짜 범위 지정·초기화, 십자선과 다중 종목 툴팁, 크게 보기, 키보드와 터치 그리기를 지원한다. Esc로 미완성 선과 크게 보기를 닫는다.
- 실제 제공 데이터는 일별 종가이므로 캔들 OHLC 값을 추정하지 않는다. 기본 종목 단독 수익률과 비교 차트의 공통 날짜 범위를 구분해 안내한다.

검증: 타입 검사, 프런트엔드 45개 테스트, 종목 정보/검색 목록 Python 10개 테스트, 실제 종목 비교·그리기·편집·저장·실패 처리·모바일 브라우저 검사, 2019년 화면 회귀 검사와 기존 툴팁 위치 36건을 통과했다. 운영 배포 결과는 검증 후 추가한다.
