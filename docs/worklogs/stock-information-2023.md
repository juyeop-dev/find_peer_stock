# 2023년 데이터 확장

범위: 2023-01-01~2023-12-31. 기존 2024년 이후 기록을 유지하면서 6개 시장 신고가·거래대금, 국내 섹터, 개별 종목 주가·실적, 투자자 수급·지수, 신용융자 잔고를 추가한다. 시작 커밋은 33e8541f1이며 작업 트리는 깨끗했다.

## 수집과 검증

- 한국 245일, 미국 250일, 일본 246일, 대만 239일, 중국 242일의 신고가·거래대금 원본을 추가했다. 각 시장의 모든 평일을 거래 기록 또는 휴장 일정과 대조했다.
- 국내 섹터 245일을 Naver 조정 일봉으로 복원했다. 고정 revision `eeed0817d1478597b738a3a6149c170ec7e3f4cb`의 FinanceData/marcap 2023 Parquet를 SHA256 검증한 후 당시 시가총액과 KRX 실제 거래대금을 반영했다. `data/korea-history-recalculation/2026-10-27-2023.json`에 근거를 기록했다.
- 투자자 수급은 두 시장의 매수·매도·순매수 및 같은 날짜 지수를 대조해 2023년 245일을 추가했다. 신용융자 잔고는 KOFIA에서 246개 보고일을 추가했다. 금융 보고일과 거래소 거래일을 임의로 같게 만들지 않는다.
- 차트에 `2023년~`을 추가하고 정적 자료·원본 조회·일일 자동 수집의 조회 시작일을 확장했다. 2024년과 2025년 선택은 유지한다.
- 이미 수집한 일봉을 재사용할 때 종목·통화와 겹치는 날짜 3개 이상의 가격을 확인한다. 기존 점은 그대로 유지하며 이전 기간만 추가한다. Spark·TradingView의 분할 조정 종가와 배당 조정 가격을 혼합하지 않는다. 파일 SHA256과 가격 규칙은 `history-cache-import.json` 및 종목별 provenance에 기록한다.
- 과거 섹터 정적 파일은 손실 없는 gzip으로 발행한다. 브라우저는 압축 자료와 호스트가 해제한 자료를 모두 읽는다. 원본 값·정밀도·메타데이터는 유지한다. 이는 확장된 전체 자료를 기존 호스팅 용량 안에 담기 위한 변경이다.

## 원본의 한계

현재 확인 가능한 상장 종목군을 바탕으로 과거를 재구성하며 상장폐지 종목 전체를 보증하지 않는다. 과거 섹터에는 현재 사업 분류를 적용했다는 안내를 유지한다. 한국 거래대금은 당시 KRX 확정 금액, 해외 거래대금은 종가×거래량 추정치다. 유럽은 당일 환율로 USD 환산하고 GBX를 GBP의 1/100로 처리한다. 원본에서 제공되지 않는 실적·가격은 추정하지 않는다.

## 재개 위치

- 실적: `python -u scripts/backfill_stock_information_2023.py collect --workers 12`, 이어서 `export`. 독립 DB는 `data/tmp_2023/information.sqlite`.
- 주가: `python scripts/extend_stock_history_2023.py`, 이어서 `python scripts/refresh_stock_information_history.py --state-dir data/tmp_2023_history`. DB는 `data/tmp_2023_history/{information,history}.sqlite`.
- 유럽: `backfill_european_new_highs.py --start 2023-01-01 --end 2023-12-31 --daily-bars 1500 --partial-history --workers 4 --universe-cache data/tmp_tradingview_chart/universe.json`, 이어서 `backfill_european_turnover.py`에 같은 날짜·깊이·부분 복원 옵션. 현재 EURONEXT 스캐너는 totalCount=856, 실제 855행을 반환해 엄격 검증을 통과하지 못했다. 2026-10-26 전수 검증 종목 목록의 원래 조회 시각을 보존해 사용한다.
- 최종 전수 감사: `python scripts/audit_stock_information_2023.py`.
- 기존 `tmp_info_update`·`tmp_2024`의 오래된 DB로 내보내지 않는다. 운영 정기 수집은 새 체크아웃의 발행 팩에서 초기화한다.

## 최종 로컬 결과

- 6개 시장 신고가·거래대금 각각 **1,477개** 일별 리포트를 추가했다. 한국 245일, 미국 250일, 일본 246일, 대만 239일, 중국 242일, 유럽 255일이다. `calendar-coverage.json`에서 12개월의 모든 평일과 휴장·거래일을 전수 대조했다.
- **22,796종목 전수 조회**를 완료했으며 모든 수집 단계의 `next=null`이다. 2023년 초를 포함하는 주가 19,562종목, 이후 상장 확인 2,758종목, 원본 제공 범위 제한 460종목, 두 점 미만/미제공 16종목이다. 전체 이력이 없는 종목은 `LSE:PNNF` 임시 상장 코드 1개이며 다른 15개는 한 점만 제공된다. 본주 PNN 등으로 임의 치환하지 않았다.
- 2023년 종료 확정 실적은 **20,051종목**, 매출 19,985종목, 영업이익 18,730종목이다. 미제공 2,745종목은 예외 목록에 남겼다. 확인된 과거 분기 실적은 0건이며 연간 실적을 분기로 나누지 않았다.
- 국내 섹터 245일, 투자자 수급·같은 날짜 지수 245일, 신용융자 잔고 246개 보고일을 추가했다. 별도 반도체 기초 자료 102종목도 원본 일봉을 재수집해 2023년 범위와 일치시켰다.
- 유럽은 5,669개 스캐너 목록에서 검증된 5,661개 종목의 일봉을 사용했다. 7개 미확인 상장(EFG, MOP, AMI0, MS8, 0HX1, SQZ, MHM)과 원본에서 주식이 아닌 것으로 확인된 1개를 제외했다. MHM은 월봉 회사명이 불일치했다. 기본 엄격 검증은 계속 실패하며, `--partial-history`를 선택한 경우에만 제외 사유를 기록하고 발행한다. 월봉이 확인되지 않는 종목의 신고가를 임의로 분류하지 않는다.
- 유럽 거래대금은 10개 외화의 실제 일별 USD 환율 255일을 검증했으며 GBX는 GBP/100로 계산했다.

## 기존 기록 보존

기존 날짜별 신고가·거래대금·섹터 원본은 수정하지 않았다. 투자자 수급과 신용 잔고의 기존 모든 값, 기존 21,085종목의 2024년 이후 실적을 대조해 일치를 확인했다.

제공처의 새 일봉 조회가 기존 날짜를 빠뜨린 439종목은 동일한 검증 상장 코드로 날짜 지정 재조회를 했다. 341종목에서 기존 날짜를 다시 확인했다. 나머지 98종목의 이전 원본은 `prior_snapshots`로 별도 보존했다. 서로 다른 분할·배당 조정 가격을 한 곡선에 섞지 않는다. 기존 21,074개 주가 이력의 모든 날짜가 현재 시계열 또는 이전 원본 스냅샷에 남아 있음을 `preservation.json`으로 확인했다. 이후 자동 갱신도 이전 스냅샷을 보존한다.

표시 파일을 재생성하면서 기존에 보정돼 있던 한국 2026년 확정 거래대금 원본과 오래된 표시용 파일의 차이도 해소했다. 기존 일별 원본은 그대로다.

## 검증과 배포 상태

Python **212개**, 원본 조회 API **24개**, 프런트엔드 계산·보존·탐색 **29개**, 타입 검사와 로컬 빌드를 통과했다. 브라우저에서 6개 시장의 2023년 월별·연간 집계와 날짜 링크, 8개 상세 경로의 2023년 차트·실적, 신용 잔고의 2023년 시작, 2023년 수급·지수의 원본 값/휴장/재조회/실패 시 보존, 과거 섹터 압축 해제·가중치·정렬, 기존 2024년 KRX 순위, 모바일 320px, 정보창 **36회**를 확인했다. 기존 2024년 전체 캘린더·상세 검사도 실행했다.

검증은 `http://127.0.0.1:4174`와 변경된 API의 로컬 실행 `http://127.0.0.1:8788`에서 수행했다. 실제 제공처 조회로 TSMC의 2022-12-20부터의 일봉과 2023년 TWD 확정 매출·영업이익·자산·차입금·현금흐름 반환을 확인했다. **운영 API 검증 또는 운영 배포 완료를 의미하지 않는다.**

최종 정적 파일을 `frontend/dist`에 준비했다. **727,885,576바이트(694.17 MiB), 80,367파일**로 기존 모든 기록을 포함하고도 호스팅 1 GiB 범위 안이다. GitHub Pages용 경로 `/find_peer_stock/`와 운영 API 주소로 생성했으며 임시 로컬 API 주소가 포함되지 않았음을 확인했다. `404.html`은 최종 `index.html`과 동일하다. 상세 빌드 정보는 `data/information-audit/2023/release.json`에 있다. 최종 공개 경로의 로컬 미리보기에서 기존 한글 IME 검색 3개 경로도 통과했다.

운영 API `find-peer-stock-live-api` 배포는 자동 승인 검토에서 **데이터 업데이트 요청에 공유 운영 서비스 배포 승인이 명시되지 않았다**는 이유로 거절됐다. 이를 우회하지 않았고 사이트 push·공개 및 API 배포를 수행하지 않았다. 사용자가 두 운영 대상의 배포를 승인하면 API 배포, 사이트 commit/push, 공개 후 검증을 이어서 진행한다.

## 운영 배포 진행

사용자가 운영 사이트와 원본 조회 API 배포를 명시적으로 승인했다. 운영 API 버전 `5691eca7-74d8-4874-aecd-5b0227fdf349` 배포를 완료했으며, 실제 운영 주소에서 TSMC의 2022-12-20부터의 일봉과 2023년 확정 실적 반환을 확인했다. 원격의 최신 자동 갱신 기록과 병합한 뒤 사이트 공개 및 브라우저 검증을 진행한다.
