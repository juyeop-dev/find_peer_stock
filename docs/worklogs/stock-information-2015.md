# 2015년 데이터 확장

2016년 확장과 같은 범위로 6개 시장 신고가·거래대금, 개별 종목 차트·확정 실적, 국내 섹터·수급·동일 날짜 지수·신용잔고·일일 반등 및 코스피/금 선물 리플레이를 추가했다. 로컬 수집·전수 감사·공개 파일·최종 정적 빌드·실제 브라우저 검증을 완료했다. 운영 사이트와 API에는 배포하지 않았다.

## 보존과 재개

- `data/tmp_2015/baseline`에 기존 가격·실적·반도체·수급·신용·리플레이·현재 종목 스냅샷을 백업했다. 기존 일별 원본 34,012개 파일의 SHA256을 `manifest.json`에 보존했다.
- 수집은 `python scripts/run_2015.py <작업 이름>`, 상태 확인은 `python scripts/status_2015.py`이다. 실적과 연속 가격의 작업 데이터베이스를 각각 `data/tmp_2015`, `data/tmp_2015_history`에 분리한다.
- `finalize_2015.py`는 의존 수집의 성공을 기다려 섹터·실적·가격을 병합하고 감사를 실행한다. `japan-gap`·`china-gap` 및 각각의 `*-adjacent` 작업으로 확인된 제공처 누락을 보완하고, `finalize_quality_2015.py`에서 원본·통화·보존 검사를 통과해야 한다. 실패한 수집을 성공이나 미제공 자료로 취급하지 않는다. `publish_2015.py --phase calendars`와 `finish_2015.py`로 공개 파일·정적 빌드를 생성한다.
- 확정 실적만 사용하며 연간·누적 실적을 임의로 분기에 배분하지 않는다. 가격 조정 기준이 다르면 곡선을 연결하지 않고 이전 관측을 별도 스냅샷으로 보존한다.

## 거래일과 원본

거래일은 한국 248·미국 252·일본 244·중국 244·대만 244·유럽 257일, 합계 1,489일이다. `data/market-closures/2015.json`에 근거와 특별 휴장일을 기록한다. 유럽은 거래소별 개장일의 합집합을 사용하고 각 거래소 휴장일을 별도로 제외한다.

- 한국: 8월 14일 임시휴장·12월 31일 연말 휴장 등을 포함한다. 당시 거래대금·시총·저가는 FinanceData/marcap revision `eeed0817d1478597b738a3a6149c170ec7e3f4cb`의 `marcap-2015.parquet`이다. 원본 URL·SHA256·수집 시각을 보존한다.
- 미국: [NYSE의 2015년 공식 일정](https://ir.theice.com/press/news-details/2013/NYSE-Euronext-Announces-2015-Holiday-Calendar-and-Early-Closings/default.aspx).
- 중국: [연간 휴장 공고](https://www.sse.com.cn/disclosure/dealinstruc/closed/list/c/c_20160104_3979217.shtml)와 [9월 3~4일 추가 휴장 공고](https://www.sse.com.cn/disclosure/dealinstruc/closed/list/c/c_20160104_3979337.shtml).
- 대만: [TPEx 2015년 공식 일정](https://www.tpex.org.tw/storage/en-us/web/bulletin/trading_date/trading_date_104.htm)을 원본 HTML로 보존했다. 7월 10일·9월 29일 태풍 휴장을 포함하고, 2016년의 토요일 보충 개장을 2015년에 복사하지 않는다.
- 유럽: [거래소의 2015년 시장 일정](https://athens.euronext.com/el/documents/10180/2312453/Xnet_holidays_2015_En.pdf/d4ee8f6b-39da-43fc-add6-ba9c2a5bc5ff)과 [Xetra 2015년 공식 일정](https://www.xetra.com/resource/blob/252786/26a3eefdbb8b939be91ec1d3d1986347/data/trading-calendar-2015.pdf). 5월 1일 영국 개장과 독일·Euronext 휴장의 차이를 유지한다.

## 원본 예외

- 2015-10-08 코스닥 수급은 Naver 원본의 12개 투자자 그룹 순매수 합계가 **45,000,000원(0.45억원)**이다. 각 그룹의 `매수−매도=순매수`는 성립하지만 시장 전체 합계는 0이 아니다.
- `data/seed/investor_source_exceptions.json`에 원본 전체 금액·원본 SHA256·시장·날짜를 고정했다. 해당 금액이 모두 일치하는 경우에만 원본 값을 그대로 발행하고 화면에 불일치를 표시한다. 금액을 보정하거나 임의의 거래를 추가하지 않는다. 다른 날짜·시장·변조된 금액은 기존과 같이 거부한다.
- 해외 캘린더는 현재 상장 종목에서 당시 거래가 확인된 자료이며 상장폐지 종목 전체를 복원했다는 의미가 아니다. 유럽의 부분 복원 안내를 유지한다.

## 수집과 원본 전수 검증

- Python 275개·API 29개·프런트엔드 85개 테스트 및 TypeScript 타입 검사 통과.
- 실제 로컬 원본 API에서 가격 시작 `2014-12-22`, 2015년 실적 요청 범위, 2015-01-02 코스피 **1,926.44**·코스닥 **553.73**과 같은 날짜 수급을 확인했다. Apple의 Yahoo 2015년 실적은 미제공이며 SEC에서 확보한 확정 실적을 별도로 병합한다.
- 실제 Chromium에서 2015년 수급 캘린더·휴장·시장별 매수/매도/순매수·같은 날짜 지수·원본 재조회·실패 시 기존 값 유지·1440/390/320px 화면 검증을 통과했다.
- 25,029종목 전수 감사: 요청 시작일 범위 확인 13,457종목, 시작일 이후 상장 10,643종목, 제공 범위 제한 914종목, 원본 미제공·두 점 미만 15종목이다. 확정 실적은 2,567종목·실제 분기 8,848건이다. 매출 제공 1,884종목·영업이익 제공 1,982종목이며, 미제공 지표를 추정하지 않았다. 종목별 결과와 한계는 `data/information-audit/2015/coverage-results.json`, `coverage-exceptions.json`에 있다.
- 주 가격 곡선 25,033개·53,590,999개 관측에서 월·분기봉이 일봉으로 저장된 경우는 0개다. 현재 상세 목록에 없는 보존 곡선도 포함하므로 상세 종목 수와 곡선 수는 다를 수 있다. 2016년 전용 복구 증빙을 요구하던 검사를 실제 2015년 원본 곡선의 주기 전수 검사로 대체했다(`daily-frequency-audit.json`).
- 기존 일별 원본 34,012개 SHA256, 현재 종목 스냅샷 29개, 확정 실적 298,523행, 주 가격 관측 49,825,392개, 신용 2,663보고일·수급 2,654일, 반도체 114종목과 리플레이 10,087개 관측의 보존 검사를 통과했다(`preservation.json`).
- 국내 섹터는 현재 분류에서 2015년 거래가 확인되는 기업군이다. 2015-01-02에는 1,465종목 중 1,456종목의 당시 KRX 금액을 대조했다. 당시 전체 상장 종목 구성과 같다는 의미가 아니다. 모든 날짜에 실제 코호트 대비 KRX 확인 비율 95% 이상을 검사한다.
- 2015년 상장 종목도 최근 1년 인라인 데이터 때문에 상장 첫해 이력이 가려지지 않도록 공개 전체 이력을 우선 확인한다. 해당 IPO 사례의 회귀 검사를 포함한다.

## 제공처 누락과 통화 검증

- Yahoo 일본 2015-12-25 원본은 2,828개 관측 중 2,737개가 거래량 0이었다. 같은 TSE 상장의 TradingView 일봉·완전한 월봉으로 2,825종목, 신고가 12개와 거래대금 상위 30개를 복원했다. 다음 거래일인 12월 28일도 같은 원본으로 신고가 선별·분류·등락률과 거래대금을 다시 산출했다. 예를 들어 Toyota의 분할 조정 종가는 Yahoo의 1,508·거래량 0 대신 TSE 원본의 1,496.6·23,234,500이다.
- Yahoo 중국 2015-02-25 원본은 2,474개 관측 중 1,396개가 거래량 0이었다. 동일 SSE·SZSE 원본 2,263종목으로 신고가 151개와 거래대금 상위 30개를 복원했다. 2월 26일도 다시 산출했다. 상장폐지·원본 미지원·실제 거래정지 등 확인되지 않는 경우를 가격으로 채우지 않았다.
- 중국 B주의 원통화 USD·HKD를 보존한다. 복원 코드가 일본용 단일 통화 가정을 이어받았던 부분을 통화 전수 검사에서 잡아 수정했다. 거래대금 순위는 해당 날짜의 검증된 통화/CNY 환율로 맞추며, 주가는 원통화로 표시한다. 환율 원본과 날짜·통화 교차 비율은 복원 보고서에 보존한다.
- 일본·중국의 복원 전 보고서와 잘못된 원본 응답은 별도 보존한다. 같은 가격 조정 기준의 완전한 곡선으로 발행하고, 독립 원본으로 확인되지 않은 채움 값 13개·17개는 주 곡선에서 제외해 원본 스냅샷에 남겼다. `japan-quality.json`, `china-quality.json`, `calendar-source-quality.json`에서 신고가·거래대금 순위·다음 거래일 등락률·연속 곡선·원본 SHA256 및 미해결 광역 누락 0건을 확인한다.

## 공개 파일과 빌드

- 원본·공개 JSON은 유지하고, 최종 빌드의 반도체·수급·리플레이·과거 반등 자료만 무손실 gzip으로 압축한다. 섹터 과거 자료는 반복 열 이름을 한 번 저장하는 형식으로 줄인다. 가격·통화·한글·null·원래 없던 속성과 행 순서를 복원해 원본과 대조한다. 기존 JSON·gzip과 호스트가 이미 압축을 해제한 응답도 읽는다.
- 공개 연속 가격 25,033개·정보 25,034개를 원본 묶음과 전수 대조했다. 섹터 과거 파일 2,466개를 모두 복원해 원본과 비교했다. 별도 보존된 곡선과 목록 외 정보도 있으므로 현재 상세 종목 수 25,029개와 발행 파일 수는 다를 수 있다.
- 캘린더 가격 파일 28,439개·1,420,528개 관측을 대조하고 이전 1,189,818개 관측을 보존했다. 일부 기존 파일명 별칭도 유지한다(`calendar-price-compaction.json`).
- 최종 빌드: `data/tmp_2015/site`, **116,178파일·1,064,611,967바이트(1,015.29 MiB)**. 운영 경로 `/find_peer_stock/`로 생성했으며 1GiB 미만이다. 빌드 단계에서 5,373개 파일을 무손실로 줄여 **84.29 MiB**를 절약했다. JSON 읽기 대체 경로와 기존 gzip 형식도 유지한다.
- 실제 Chromium에서 최종 압축 빌드의 두 캘린더 × 6개 시장의 2015년 연간·월간 집계, 8개 상세 경로의 `2015년~` 차트, 원본과 같은 확정 실적 행 수 또는 미제공 안내, 신용잔고, 압축된 코스피/금 리플레이, 원본 정보·가격 재조회와 1440/320px 화면을 통과했다. 수급은 별도로 1440/390/320px·원본 불일치 안내·실패 시 기존 값 유지까지 검증했다.
- 최종 빌드는 운영 API 주소를 유지한다. 브라우저 검증에서 원본 재조회만 검증한 로컬 API 소스로 연결했으며, 운영 API에 2015년 지원이 배포됐다는 의미는 아니다. 실제 로컬 원본 응답을 사용했고 가격이나 매매 금액을 모의 값으로 대체하지 않았다.
- Windows에서 공개 gzip 파일을 잠시 읽는 중 교체가 거부된 경우를 확인했다. 내용이 같은 파일은 유지하고, 실제 교체는 짧게 재시도하도록 보완했다. 재발행과 최종 원본 대조를 통과했다.
- `python scripts/status_2015.py`의 수집·감사·발행·빌드 단계가 모두 완료됐다. 최종 원본 대조는 `data/information-audit/2015/publication.json`, 단계·실행 결과는 `data/tmp_2015/stage-*.json`과 테스트 결과 기록에서 확인한다. 운영 배포는 별도다.
