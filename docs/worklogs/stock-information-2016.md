# 2016년 데이터 확장

기존 연도 확장과 같은 범위로 6개 시장 신고가·거래대금, 종목 차트·확정 실적, 국내 섹터·수급·동일 날짜 지수·신용잔고·일일 반등 및 코스피/금 선물 리플레이를 추가했다. 로컬 수집·전수 감사·공개 파일 생성·실제 브라우저 검증·정적 빌드를 완료했다. 운영 사이트·API에는 배포하지 않았다.

## 보존과 재개

- `data/tmp_2016/baseline`에 기존 종목 정보·가격·반도체·수급·신용·리플레이·현재 종목 스냅샷을 백업했다. 기존 일별 원본 30,544개의 SHA256은 `manifest.json`에 기록했다.
- 실적은 `data/tmp_2016/information.sqlite`, 가격은 `data/tmp_2016_history`에 분리한다. `python scripts/run_2016.py <작업 이름>`으로 재개하고 PID·명령·종료 상태·로그를 남긴다. 실행 중인 작업은 중복 실행하지 않는다.
- 네트워크 권한 거부로 생성된 초기 실적 조회 체크포인트 4,376개는 삭제해 실제 원본 조회 대상으로 되돌렸다. 접근 거부를 원본 미제공으로 저장하지 않도록 수집기를 보완했다.
- 확정 실적만 표시하며 연간·누적 수치에서 미제공 분기를 추정하지 않는다. 가격 조정 기준이 다른 원본은 한 곡선으로 연결하지 않고 기존 관측을 별도 스냅샷으로 보존한다.

## 거래일과 자료원

거래일 기준은 한국 246·미국 252·일본 245·중국 244·대만 244·유럽 257일로 합계 1,488일이다. `data/market-closures/2016.json`에 근거와 예외 날짜를 저장한다. 실제 원본 거래일과 전수 대조한다.

- 한국은 4월 13일 선거일·5월 6일 임시공휴일·12월 30일 연말 휴장을 포함한다. KRX 금액·시총·저가 원본은 FinanceData/marcap revision `eeed0817d1478597b738a3a6149c170ec7e3f4cb`의 2016 Parquet이며 URL·조회 시각·SHA256을 함께 보존한다.
- 대만 공식 토요일 개장일은 1월 30일·6월 4일·9월 10일이다. [TPEx 2016년 공식 일정](https://www.tpex.org.tw/storage/en-us/web/bulletin/trading_date/trading_date_105.htm)을 원본 HTML로 보존했다. 태풍 휴장일 7월 8일·9월 27일·9월 28일도 별도로 반영한다. 공식 TWSE·TPEx 시세와 전후 실제 거래일 OHLC 조정 기준이 일치하는 종목만 복원한다.
- 중국은 [상하이거래소 공고](https://www.sse.com.cn/disclosure/dealinstruc/closed/list/c/c_20160104_4028872.shtml), 미국은 [Nasdaq 일정](https://www.nasdaq.net/PublicPages/assets/MyMID/2016_Trade_Calendar.pdf), 유럽은 [Euronext 일정](https://www.euronext.com/en/about/media/euronext-press-releases/euronext-announces-calendar-2016)과 [독일 현물시장 일정](https://cashmarket.deutsche-boerse.com/resource/blob/259998/85c710e77ed5d595695f5b1d6418eac7/data/trading-calendar-2016.pdf)을 기준으로 한다. 유럽 거래소별 휴장 차이를 유지한다.

## 상태 확인

```powershell
python scripts/status_2016.py
```

원본 수집 뒤 `finalize_2016.py`가 의존 단계와 전수 감사를 이어서 실행한다. `stage-*.json`과 `coordinator.error.log`에서 실패를 확인한다. 모든 수집과 감사가 통과하기 전에는 완료로 간주하지 않는다.

## 확인한 수집 결과

- 신고가·거래대금 각각 한국 246·미국 252·일본 245·중국 244·대만 244·유럽 257일을 실제 원본과 전수 대조했다. 국내 섹터·수급·동일 날짜 지수는 246일, 신용은 247보고일, 일일 반등은 246일이다.
- 국내 섹터와 거래대금 246일을 당시 KRX 금액·시가총액으로 재계산했다. 원본 누락 날짜는 없다.
- 24,996종목의 실적 조회를 마쳤다. SEC 원본 확정 실적 2,681종목·12,052행을 적용했으며, 미제공 22,315종목은 별도 예외로 기록했다. 과거 분기를 추정하지 않았다.
- 반도체 114종목과 코스피·금 선물 리플레이의 2016년 시작 구간을 수집했다. 대만 토요일 3일은 공식 원본과 전후 OHLC 기준을 검증해 복원했다.
- 실제 원본 API에서 가격 조회 시작 `2015-12-21`, 2016년 실적 요청 범위, 2016-01-04 코스피 1,918.76·코스닥 677.79 및 같은 날짜 수급을 확인했다(`local-api.json`).
- 실제 Chromium에서 2016년 수급 캘린더·매수/매도/순매수·같은 날짜 지수·시장 합계·원본 재조회·실패 시 값 보존·1440/390/320px 검증을 통과했다. 근거는 `data/tmp_2016/investor-browser.log`와 `ui/`에 있다.
- 캘린더 종목 가격의 공개 파일 28,406개를 무손실 gzip으로 발행한다. 기존 관측 1,189,818개를 전수 대조했고, 원본 바이트와 정밀도를 보존하며 63,750,689바이트를 줄였다(`calendar-price-compaction.json`). 이전 `%` 파일명 별칭도 내용 그대로 보존했다. 화면은 gzip·호스트가 이미 해제한 응답·이전 JSON 대체 경로를 지원한다.
- 원본 일봉의 중복 날짜는 파서에서 거부하고 대체 원본으로 재조회한다. 임의로 중복 가격 중 하나를 골라 저장하지 않는다.

## 제공처 오류 보완

- Yahoo의 일본 2016-07-11 시세는 Toyota·Sony·SoftBank 등에서 전일 종가와 거래량 0을 반환했다. 같은 TSE 상장의 TradingView 실제 일봉·월봉으로 2,816종목, 신고가 27개와 거래대금 상위 30개를 복원했다. 다음 거래일 7월 12일의 등락률 55개도 실제 7월 11일 종가로 다시 대조했다. 2,816종목의 연속 가격과 거래대금 순위를 전수 검증했다(`japan-quality.json`). 변경 전 보고서는 `data/tmp_2016/japan-replaced-reports`에 보존했다.
- 분할 조정 기준 예: Toyota `TSE:7203`의 해당 날짜 종가는 1,060.2, 조정 거래량은 69,736,500이다. 기존 Yahoo 응답의 1,011·0을 차트 주 데이터로 사용하지 않는다. 조정 기준이 다른 가격은 연결하지 않고 한 제공처의 완전한 연속 곡선과 이전 스냅샷을 함께 보존한다.
- Yahoo Spark의 `max&interval=1d`는 실제 `dataGranularity=1mo` 또는 `3mo`를 반환했다. 8,184개 월·분기봉 응답을 찾아 기존 일봉·검증된 원본 캐시·명시적 일봉 재조회로 복원했다. 국내 종목은 Naver 실제 일봉도 대조한다. 오래된 원본이 다시 제공되지 않은 3종목은 보존된 일봉을 유지하고 예외를 남겼다. 일봉 주 데이터에 남은 월·분기봉은 0개다(`daily-frequency-recovery.json`).
- 파서는 제공처의 실제 주기가 `1d`가 아니면 저장 전에 거부한다. 월·분기봉 원본은 보존 목적의 스냅샷으로만 두며, 일봉 대체 곡선으로 발행하지 않는다. 실제 월봉·분기봉 응답을 거부하는 회귀 테스트를 포함한다.

## 최종 검증과 산출물

- 24,996종목을 전수 감사했다. 2016년 시작 구간 확인 13,875종목, 이후 상장 9,896종목, 원본 범위 제한 1,205종목, 원본 미제공·두 점 미만 20종목이다. 종목별 근거는 `coverage-results.json`, 예외는 `coverage-exceptions.json`에 있다. 확정 실적은 2,681종목, 실제 분기 보고는 9,347건이다.
- 기존 일별 원본 30,544개 SHA256, 확정 실적 286,375행, 주 가격 관측 45,736,153개, 신용 2,416보고일·수급 2,408일, 반도체 114종목, 리플레이 7,110개 관측 및 현재 종목 스냅샷 29개를 보존했다(`preservation.json`). 공개 파일 생성 뒤에도 보존 감사를 다시 통과했다.
- Python 272개·API 27개·프런트엔드 80개 테스트와 TypeScript 타입 검사를 통과했다. 실제 Chromium에서 두 캘린더 × 6개 시장의 연간·월간 집계, 상세 8개 경로의 `2016년~` 차트, 원본과 같은 확정 실적 행 수 또는 명시적 미제공 안내, 신용잔고·원본 정보/가격 재조회·1440/320px 화면을 검증했다. 수급은 별도로 1440/390/320px를 검증했다.
- 전체 공개 가격 파일 24,995개와 정보 파일 25,001개의 종목·통화·가격 관측·확정 실적·현재 시세·지표·2016년 제공 범위를 원본 묶음과 대조했다. 보존된 이전 파일을 포함한 발행 파일 수는 실제 감사 대상 종목 수와 다를 수 있다.
- 최종 정적 묶음: `data/tmp_2016/site`, 112,588파일, **998.67 MiB**. 운영 경로 `/find_peer_stock/`로 빌드했으며 원본과 공개 파일을 다시 대조했다(`publication.json`). 빌드 도구의 상위 폴더 조회가 로컬 권한 제한으로 한 번 실패해, 필요한 읽기 권한으로 재실행한 최종 빌드가 성공했다.
- 실제 브라우저 기록은 `data/tmp_2016/stock-browser.log`와 `investor-browser.log`, 단계별 성공 상태는 `stage-*.json`에 있다. `python scripts/status_2016.py`에서 모든 수집·감사·발행·브라우저·빌드 단계가 완료됐음을 확인할 수 있다. 운영 사이트·API 배포는 수행하지 않았다.
