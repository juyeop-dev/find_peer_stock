# 유럽 2026년 9월 복원 자료 보관

Yahoo 과거 일봉 복원본은 5,411개 스캔 종목 중 3,592개의 이력만 확보했습니다. 수집률 98.4%는 거래일 이력이 없던 1,762개를 분모에서 제외한 수치입니다. 같은 9월 21일 TradingView에서는 4,873개 종목의 당일 거래가 확인됐습니다.

거래대금 복원본은 GBX(펜스)·EUR·CHF 등을 환산하지 않고 정렬해 9월 1~17일의 상위 30개가 모두 런던 종목이 됐습니다. 신고가 복원본에도 거래량 0인 종목이 포함됐습니다. 원본은 조사와 재복원을 위해 이 폴더에 보존하고, 사이트에서는 게시하지 않습니다. 9월 23일 거래대금은 신뢰할 수 있는 전체 순위를 복원할 수 없어 공백으로 둡니다.
